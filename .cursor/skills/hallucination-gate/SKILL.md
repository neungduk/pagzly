# 환각 방지 게이트

## 만들지 않는 것

- 입력 정보에 없는 수치, 인증, 수상, 성분 효능, 비교 근거.
- 근거가 없는 비교는 퍼센트 대신 ✓ / – 로 표시한다.
- 가짜 인물·전문가 프로필, 가짜 후기 인용문, 이름·직함·인증 마크.

## 인물 사진

- 인물이 나오는 사진 위에는 글자를 올리지 않는다.
- 사용 장면은 얼굴을 제외한 크롭(`upper_body`, `hands`)을 쓴다.
- 후기·인증·전문가 슬롯에 인물 사진이 배정되면 `text_only`로 바꾼다.

## 게이트 유지

- 환각 방지 게이트를 약화하지 않는다. 게이트를 느슨하게 하는 변경이 필요해 보이면 하지 말고 먼저 사용자에게 묻는다.
- 표시 방식을 바꾸는 수정도 새 문구를 지어내지 않는다(예: 질문형 제목일 때만 "Q." 리드를 붙이고, 문장을 새로 만들지 않음).

## 기타

- 경쟁사 이름은 Pagzly 출력과 UI에 쓰지 않는다.
- `illustration_banner`(250차, 사용자 결정 대기)는 건드리지 않는다.
