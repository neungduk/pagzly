# 유료 API 가드

## 실행 전 승인

- 유료 API 호출과 새 유료 생성은 사용자의 명시적 허락 없이는 금지다.
- 필요하면 실행하지 말고 아래 형식으로 제안만 한다.

```
제안(실행 안 함, 승인 필요)
- 무엇: (예: 익명 사용 장면 생성)
- 카테고리·횟수: (예: 패션 1 · 전자 1 · 리빙 1 = 3컷)
- 예상 비용: (예: 컷당 약 $0.05, 합계 약 $0.15~0.20 / 크레딧 N)
- 실행 후 점검: (같은 소스 2회 상한, 얼굴 없는 크롭, 인물 위 글자 없음, 패리티 0, 하이드레이션 0, 비교 캡처)
```

- 무료 검증 스크립트도 실제 생성 경로를 타면 안 된다(예: 240cha 스크립트는 `SKIP_LIVE=1`로만 실행).

## 수정 금지 파일

- 사진합성 알고리즘: `lib/lifestyle-product-composite.ts`, `lib/photo-enhance.ts`, `lib/photo-composite.ts`.
- 수정이 필요하면 이유와 수정안만 보고서에 올리고 승인을 기다린다.

## 플래그와 크레딧

- 생성 기능 플래그(예: `USAGE_SCENE_GENERATION_ENABLED`)는 허락 없이 켜지 않는다.
- 크레딧 차감은 응답 직전에 한다. 이 순서를 바꾸지 않는다.

## 로그

- 로그에 키·개인정보·URL을 남기지 않는다. 이미지는 번호만 쓴다.

## 크롤링

- 쿠팡·G마켓(봇 차단), 올리브영(상세 이미지 로드 안 됨)은 크롤링을 시도하지 않고 "확인 안 됨"으로 표기한다.
