# 493차 — 광고 표현 규칙 보강(협회 해설서 2025 기반 데이터) + 독립 시안 시험

## 0. 규칙
- 유료 호출(AI/OCR)·Production·main 금지. 코드 삭제 금지. 상세페이지 코드·화면 문구(소개·면책) 변경 금지. **"위반" 단정 금지**(결과는 "확인 필요"만). 새 판정을 임의로 만들지 말고 `review/data/ad-phrases-kr_draft_v0.1.json`에 있는 것만 사용.
- 목표는 `review/493-targets.md`에 코드 전에 기재. 파일은 Read 후에만 Write/Edit. 마무리 전 `npx tsc --noEmit`, `npm run build` 통과. 커밋 최대 4개.

## 1. 배경
- 492차에서 광고 규칙(ADV)은 규칙표 `examples`와 소수 고정 패턴에만 의존했다. 기획 담당이 별도로 만든 시안 `i3_ads.pdf`("기미·주근깨 완치! 피부 재생! 아토피 치료!")는 "의약품 오인" 1건만 잡히고, 기능성 오인("기미·주근깨")과 "아토피" 등은 별도로 짚지 못했다.
- 식약처 지침 대신 접근 가능한 **대한화장품협회 광고자문 기준 및 해설서 2025**(지침 개정 반영)를 근거로 표현 패턴 데이터를 새로 만들었다: `review/data/ad-phrases-kr_draft_v0.1.json` (21개 항목, 의약품 오인·기능성 오인·소비자 오인·실증 필요). 기획 담당이 이미 레포에 넣어 두었다. 데이터는 초안이며 `source_verified`는 협회 해설서 기준이다(식약처 원문 대조는 미완).
- 독립 시험 시안 6개를 `review/data/samples/independent-492/`에 넣어 두었다(i1 정상 2단, i2 전성분 없음, i3 과장 광고, i4 향료+INCI 알레르기, i5 기능성, i6 사용기한·제조번호 없음). 492차 코드는 이 6개에서 필수항목은 기대대로 판정했다(기획 담당 실측).

## 2. 항목
### A. 광고 표현 스캔 구현 (판정 로직 최소 변경)
- `ad-phrases-kr_draft_v0.1.json`을 로드해 PDF 텍스트에서 각 항목의 `patterns` 일치를 찾는다. 일치하면 **항목 제목 단위로 "확인 필요"** 한 건씩(같은 항목에서 여러 패턴이 일치하면 한 건으로 묶고 찾은 표현 최대 3개를 `format-found` 규칙으로 표시).
- `condition`: `non_functional` 항목은 사용자가 "기능성화장품"을 체크하지 **않았을 때**만 확인 필요. 체크했으면 "기능성 심사·보고 범위 내 표현인지 확인하세요" 안내(같은 항목, 문구만 다르게)로 낮춰도 되고, 이번 차수에서는 단순히 생략해도 된다 — 선택하고 notes에 기록.
- `needs_evidence: true` 항목은 "확인 필요"에 **"근거 자료(인체적용시험 등)가 필요한 표현일 수 있어요"** 한 줄을 덧붙인다. 새 카피는 이 한 줄과 항목 제목 외에 만들지 말 것.
- **스캔 제외 영역**: 전성분 영역(성분명 `알부틴`, `나이아신아마이드` 등)과 `사용할 때의 주의사항` 영역·고시 문구는 스캔에서 제외한다(데이터 `meta.matching_notes` 참고). 영역 식별이 불가하면 스캔은 하되 해당 항목 안내에 "성분·주의사항 문구는 제외하고 확인하세요"를 덧붙이지 말고 notes에 한계로 기록.
- 기존 ADV 규칙(규칙표 KR-ADV-001~007)과 중복 표시되지 않게 통합: 같은 문구가 두 번 보이면 안 된다. 화면에는 한글 항목 제목만(내부 id 노출 0).

### B. 오탐 시험 (중요)
- 정상 시안 i1·i5와 샘플 C, 492 변형 정상본에서 광고 확인 필요가 **0건 또는 합리적 최소**여야 한다. 특히: 전성분의 `알부틴`·`천연` 포함 성분명, 주의사항의 `전문의`, 포장재 `재생지`, `보다` 같은 일반 단어, `100%` 가 `정제수 100%`처럼 쓰인 경우. 오탐이 나오면 패턴 데이터를 고치지 말고 **스캔 로직(영역 제외·단어 경계)** 을 고친다. 데이터를 바꿔야 하면 notes에 이유를 기록하고 바꾸지 말고 보고(데이터 소유는 기획 담당).

### C. 누락 시험
- i3_ads: 기대 — 의약품 오인(치료·재생·완치·아토피), 기능성 오인(기미·주근깨, 기능성 체크 없음) 이 각각 별도 항목으로 확인 필요. 변이 시험(`label-check-mutation-492`)에 광고 변이 5종 이상 추가: 미백, 주름개선, 병원용, 줄기세포/엑소좀, 피부나이 n세, 최고/즉시, `30% 개선` 각각 주입 시 해당 항목만 추가로 잡히고 나머지 항목은 변하지 않아야 한다.
- 독립 시안 6개를 `scripts/regression/label-check-493.ts`에 고정 기대값으로 등록(기대값은 아래 표를 사용):

| i1_ok_twocol | possible 0. 광고 확인 필요 0 |
| i2_no_ingredients | 전성분 possible. 나머지 필수항목 통과 |

### D. 알려진 의문 (조사만, 임의 수정 금지 → notes 기록)
- i1(정상, 향료·알레르기 성분 없음)에서 "알레르기 유발성분 25종 표시"가 **확인 필요**로 나온다. 향료가 없는데 왜 나오는지 원인을 찾아 기록하고, 규칙 문구상 정상 동작이면 그대로 둔다. 규칙에 비해 과도하면 보고(수정 제안만).
- "가격"·"화장품 바코드"가 대부분의 시안에서 확인 필요로 나온다. 규칙표 문구 근거를 인용해 기록(이번 차수 수정 대상 아님).
