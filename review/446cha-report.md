## 1. 노랑~초록 대비 결함 (항목 1)
- 원인: 팔레트 곡선이 약 30~180°에서 밝은 색을 줘서 deepAccent·accentText가 옅은 면 위에서 4.1 안팎, accent 면 위 종이색 글자(POINT 칩·말풍선·카드 머리)가 3.9~4.4, 색상이 돌아간 슬롯 테마(참고 카드 제목)는 2.96까지.
- 수정(한 곳, `lib/palette-v4.ts v4SafeTheme`): 색상·채도 유지, **명도만 낮춰** `accentText`·`deepAccent`는 옅은 면(`#EDEDE4`) 위 4.6:1, `accent`는 종이색 글자 4.6:1. 라이브·export가 테마를 처음 받는 자리(`applyPackTone` 직후)와 팔레트 슬롯 4개(`extendThemeFor`)에서 같은 함수. 가격 기호는 색만 간접 보정 — **구매 섹션 마크업·`data-pz-buy`·`cta_price` 구조 변경 0**(회귀로 색상 12단에서 `pagzly-cta`·`data-info="buy"` 수 불변, 라이브 `data-pz-buy` 소스 1개 확인).
- 회귀 `contrast-wheel-446`: 12색 × 3단 × 4픽스처 R7 0, 보정 불변식(두 번 적용 같음·색상 8° 이내·명도만 하락·이미 안전하면 같은 객체).
- 이 보정은 합성 픽스처에 노랑~초록 색상을 줬을 때 드러난 실사용 위험이다(레몬·녹차·식품·아웃도어 사진 지배색이면 그대로 난다).

## 2. 색 응집력 (항목 2)
- 지표(`scripts/color-budget.ts`): export 390폭에서 최상위 구간 면 색 → 중립(chroma < 0.055·거의 흰/검정) 제외 → 색상 30° 창 단위 색상군 수. 린트 R18(warn: >3)·회귀 `color-budget-446`이 같은 함수.
- 규칙(v4): `extendThemeFor` 슬롯 4개를 **색상 2군**으로 — 보조 이동 ±40° 이내, 3차 슬롯 = 대표색 계열 명도 사다리, 포인트 슬롯 = 보조 계열 명도 사다리(패션은 대표색 계열 채도 변주). v3의 보색(+150~180°)·삼각(±120°) 슬롯은 v4에서 폐기. `v4Palette` 그라데이션 두 번째 색의 보조 이동도 ±40°(팝 120°·스트리트 180° 무드가 다른 색상군으로 튀던 것). 패션 `photo-tonal`·뷰티 소프트 면 규칙은 그대로(교차 시 더 엄격한 쪽).
- **페이지 사이 다양성 유지**: 회귀로 대표색 색상 30° 칸 ≥ 8(합성 21종), 히어로 면 색 겹침 ≤ 2/21 회귀도 그대로 통과.
- 눈 검수(`review/446-verify/color-before-after/before|after/`): 뷰티 — 연두·분홍·하늘·청록 4군 → 청록+하늘빛 2군, 흰·민트·짙은 청록 띠 리듬 유지(정돈됨, 단조롭지 않음). 테크 — 초록 계열 2군(정돈됨; 대표색이 초록이라 테크 제품치고 따뜻하다는 인상은 픽스처 입력 탓). 패션 — 플럼 + 웜 크림(정돈됨, 보라 채도는 다소 높음). 생활·빈약은 지표만 확인.
- 부수 효과: 면이 비슷해져 옅은 면 키를 하나로 합쳤다(§4). **한계**: 합성 자리표시자 사진이라 실사진과 섞였을 때의 조화는 판단하지 못함.

## 7. 새로 발견한 문제·주의
1. v4 색 예산은 **v4 한정**이다. v4 off(예전 화면)는 여전히 색 4~5군·노랑~초록 대비 결함이 그대로다(off = 445차 끝과 동일이 요구사항).
2. 대표색이 채도 높은 어두운 색(예: 합성 반려동물 `#2020CA` 파랑)이면 B형 히어로 포화 면이 매우 강하다(규칙은 4.5:1만 보장). 실사진 대표색에서는 확인 필요.
3. 린트 R18은 면 색만 센다(글자색·아이콘·사진은 제외). 색 응집력의 실제 인상은 실사진과 함께 눈으로 확인해야 한다.
4. 번호 배지의 숫자는 칸 위치(2, 3 …)라 첫 칸이 아이콘이면 "2"부터 시작할 수 있다(의도한 단순 규칙).

v4 기본 on 판단은 445차와 같다(코드·회귀 기준 가능, off로 즉시 롤백, 결제·편집 UI 미수정). 이번 차수로 실사용 위험이던 노랑~초록 대비 결함은 제거(색상환 전수 0)했고 "알록달록" 인상은 지표상 해소했다. 남은 위험은 실사진과 섞였을 때의 색·히어로 모양, 저장 세션, 실제 환경 빌드(위 PC 10·11·7·9)이다.
