## 1. 배경 (기획 담당의 비교 결과)
올리브영 미스트 1위 상품 상세(약 25,000px)와 우리 실사 결과를 나란히 본 결과, 격차의 핵심은 아키타입 분화가 아니라 다음이다.
1. 경쟁 쪽은 상품 사진을 **무대 위에 합성한 큰 키비주얼 1장**(받침대·큰 숫자·빛 번짐)에 **특징 말풍선 4개**를 제품 둘레에 붙인다. 우리는 원본 사진을 네모 틀에 넣고 파스텔 면을 깔 뿐이다.
2. 경쟁 쪽은 **상품 지배색 3색**(금·검정·크림)을 끝까지 유지한다. 우리는 **사진 배경에서 뽑은 `#A7BED0`(연한 청회색)** 이 주조색이라 노란 오일·흰 병인 실제 상품과 무관한 연보라/하늘색/크림이 섞인다.
3. 경쟁 쪽은 블록 하나에 **큰 문장 1~2줄 + 사진 1개**. 우리는 영문 라벨·POINT 번호·밑줄·알약·장식이 한 블록에 겹친다.
4. 경쟁 쪽은 **같은 색 계열의 어두운 면 1구간**(큰 전환)으로 리듬을 만든다.

## 2. 항목
### A. 팔레트를 상품에서 뽑기 (최우선)
- 톤앤매너 추출(결과 화면 "톤앤매너 추출 #A7BED0" 단계) 코드를 찾아 현재 입력(사진 전체 평균? 배경 지배색?)을 `review/482-notes.md`에 기록하고, **상품 영역의 지배색**을 쓰도록 바꾼다.
  - 방법 우선순위: ① 이미 만들어진 컷아웃(배경 제거) 알파 마스크 안쪽 픽셀만 샘플 ② 없으면 사진 중앙 60% 영역에서 채도 가중 군집(K=3) ③ 그래도 안 되면 기존 방식 폴백.
  - 흰/회색/검정 같은 무채색 병이 지배적이면 **내용물·라벨의 채도 있는 색**(예: 노란 오일)을 주조색 후보로 올린다(채도 가중).
- 결과를 **3색(주조·보조·어두운 면) + 포인트 1색**으로 고정하는 `lib/palette-from-product-482.ts` 추가. 배경 AI 면(backdrop)·섹션 면·알약·구분선이 **이 3색 계열(hue ±25°)에서만** 나오도록 `color-roles-v5.ts` 입력을 교체. 기존 "색 이동(hue shift)" 규칙은 이 팔레트 안에서만 적용.
- 시험: live-481 픽스처로 주조 hue가 상품(노랑 계열)에 가까운지, 페이지 전체 면 색이 3 hue 구간 이내인지 자동 검사. 기존 극단 팔레트 4종 통과 유지.

### B. 키비주얼 합성 (첫 화면 + 요약 블록에 1장씩)
- 입력: 이미 생성된 컷아웃 PNG(rembg 결과)가 있으면 사용, 없으면 원본 사진으로 폴백(합성 생략하고 현행 유지).
- 로컬 합성 레시피 3종을 `lib/keyvisual-482.ts`로 구현(SVG/CSS 레이어, 새 이미지 생성 없음):
  1. **스테이지**: 제품 아래 받침대(타원+그림자), 뒤에 큰 원/아치 면(주조색 계열), 제품 바로 뒤 큰 숫자 또는 큰 도형 1개(기존 입력 수치가 있을 때만, 없으면 도형).
  2. **빛 번짐**: 제품 뒤 방사형 그라데이션(밝은 쪽 1개), 은은한 노이즈.
  3. **콜아웃 말풍선 3~4개**: 제품 둘레에 둥근 말풍선+가는 연결선, 문구는 **기존 특징 카피**(points/하이라이트의 짧은 문장, 최대 12자로 말줄임 금지: 길면 해당 말풍선 생략). 말풍선은 제품 위를 가리지 않게 배치(제품 박스 바깥, 좌우 교차).
- 아키타입별로 레시피 1종을 배정(예: editorial=스테이지 연한 톤, luxe=어두운 면+빛 번짐, pop=큰 도형+말풍선 3개 …). 같은 상품은 항상 같은 결과(결정적).
- 사진이 제품 컷이 아니거나(손에 든 컷, 라이프스타일) 컷아웃이 없으면 키비주얼을 만들지 않고 기존 블록으로 폴백. 가격·고지·구매 카드·접점 위치 불변.
- 시험: 합성 결과에서 말풍선이 제품 박스와 겹치지 않음(좌표 검사), 텍스트 대비 4.5:1, 가로 넘침 0, export 증가량 상한(키비주얼 1개당 +4KB 이하 목표, 총합 140% 이내).

### C. 블록 단순화 (큰 문장 1~2줄 + 사진 1개)
- 사진 중심 블록(points/phototext/bleed)에서 **영문 라벨·POINT 번호·밑줄·알약·장식 도형을 합쳐 2개 이하**로 제한(최대 3). 초과분은 제거 우선순위: 장식 도형 → 밑줄 → 알약 → 영문 라벨. 제목은 한 블록에 하나, 크기는 본문의 2.2배 이상.
- 포인트 제목 밑줄이 글자와 겹치는 문제를 같이 해결(밑줄은 글자 아래 간격 고정 또는 제거).
- 시험: 실사 픽스처 블록별 시각 요소 수 평균 ≤ 2.5, 최대 ≤ 4. 제목 대비 본문 크기 비율 검사.

### D. 어두운 전환 구간 1개
- 페이지 중간에 **주조색 계열 어두운 면** 구간을 정확히 1개 추가(기존 구분 띠를 대체, 새 카피 금지): 가장 길이가 긴 문장 하나를 큰 글씨로 두는 장면. 아키타입별 위치를 다르게(전체의 35~60% 지점).
- 어두운 면 위 글자는 기존 `--pz-surface/--pz-on-surface` 규칙을 따른다. 대비 실패 0.
