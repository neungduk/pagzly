# 495차 노트

## 보관 방식 (선택)
- **사용자당 최근 200건**. insert 직전 건수가 200 이상이면 오래된 행부터 삭제 후 insert (`LABEL_CHECK_MAX_RUNS_PER_USER`).

## 레이트 리밋 상수
- 비회원: 10/분 (IP)
- 회원: 30/분 (user id)

## RLS 정책 검토 (실DB 시험 불가 — SQL 검토만)
- `select`/`insert`/`delete` 모두 `auth.uid() = user_id`.
- `update` 정책 없음 → 요약 불변.
- 타 사용자 id로 select/delete 시도 시 RLS가 행을 숨기거나 0건 삭제. 서비스 롤 키는 API에서 사용하지 않음(사용자 세션 클라이언트만).

## 약관·개인정보 문구 초안 (법률 검토 대상 — 페이지 미반영)
> 표시사항 사전 점검 결과는 로그인한 계정의 ‘내 결과’에 요약(항목 제목·상태·짧은 안내)으로만 저장됩니다. 업로드한 PDF 파일과 파일명, 추출 원문은 서버에 저장하지 않습니다. 회원은 ‘내 결과’에서 본인 요약을 열람·삭제할 수 있습니다. 비회원 점검은 저장되지 않습니다.

## 확인하지 못한 항목
- 마이그레이션 실적용·실로그인 E2E·타 계정 침투 시험 미실시.
