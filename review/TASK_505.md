## 1. 배경
사용자가 식약처 원문 3건을 추가로 제공했고 기획 담당이 아래 데이터를 갱신/추가했다(모두 `review/data/`).
- `allergens-kr-25_v1.json` — 고시 별표2 원문 기준 25종(국문명·CAS 확정, INCI는 미대조). 초안 대비 국문명 3건 정정(아이소유제놀, 알파-아이소메틸아이오논, 메틸 2-옥티노에이트). 기존 `allergens-kr-25_draft.json`은 삭제하지 말고 남긴다.
- `kr-cautions_draft_v0.2.json` — v0.1 + `common_cautions`(시행규칙 별표3 제1호 공통사항 4개).
- `ad-phrases-kr_draft_v0.2.json` — `meta.evidence_requirements`(실증 규정 체크포인트 6줄) 추가.
- `kr_label_rules_draft_v0.1.json` — KR-LBL-022·009 notes 갱신.

## 2. 항목
A. **알레르기 로더 교체**: 기존 초안 대신 `allergens-kr-25_v1.json`을 읽는다. 매칭은 국문명(원문 표기) 우선, CAS 번호 문자열 포함 시도 보조(라벨에 CAS가 쓰이는 경우는 드묾 — 구현이 복잡하면 보류하고 사유 기록), INCI 영문명은 기존 방식 유지. 국문명 공백 변형(`메틸 2-옥티노에이트` / `메틸2-옥티노에이트`)과 `이소` vs `아이소` 표기 차이를 정규화로 둘 다 인정하되, 화면에는 **고시 표기(원문)** 를 보여 준다. 임계값 문구는 `thresholds` 값을 읽어 표시(하드코딩 제거).
B. **공통 주의사항 판정**: `common_cautions` 4개의 `match_keys_ko`를 `사용할 때의 주의사항` 구간(식별 실패 시 전체)에서 확인. 모두 없음 → "공통 주의사항 문구 누락 가능(확인 필요)"로 한 건, 일부만 없음 → 없는 항목 제목만 나열. 기존 KR-LBL-009의 판정과 **중복 표시되지 않게 통합**(기존이 존재 여부만 보았다면 그 항목의 설명을 확장). 기능성화장품(규칙 제2조제6·7호)은 공통사항을 외부 포장에 써야 한다는 안내를 한 줄 덧붙임(별표4 8.). 새 카피는 이 한 줄과 항목 제목에 한정.
C. **실증 체크포인트**: 광고 `fix_kind: evidence` 항목의 접힘 영역에 `meta.evidence_requirements.points_ko` 중 상위 3줄을 "근거 자료 확인" 아래 표시(기존 `fix_ko` 아래). 같은 3줄이 항목마다 반복되므로 결과 하단에 한 번만 모아 표시하는 방식을 택하고 선택 사유를 notes에. 법적 충족 판정 금지.
D. **검증 스크립트**: `validate:rules`에 `allergens-kr-25_v1.json`(25개, no 1~25 연속, ko·cas 존재, CAS 형식 정규식)과 `kr-cautions` v0.2 `common_cautions` 검사 추가.

## 3. 시험 (`label-check-505.ts`)
- 알레르기: 리모넨·리날룰 표기 시 통과, 향료만 있고 성분 없음 → 확인 필요(기존 동작 유지), `이소유제놀`과 `아이소유제놀` 둘 다 인식, `메틸2-옥티노에이트` 인식, 기존 시안 A/B/C·i1~i6 결과 변화 전/후 표.
- 공통 주의사항: 4개 문구 있는 합성 입력 통과, 하나 없음 → 해당 제목만 나열, 모두 없음 → 한 건.
- 정상 라벨(i1, i5, sample C, us1)에서 새 지적 0 또는 합리적 최소.
- 기존 회귀 유지.
