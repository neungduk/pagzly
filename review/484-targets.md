# 484차 목표 (코드 전)

## 성공 기준
1. **진짜 PDF**: Chromium 임베드 한글 샘플 A/B/C로 검수. 483 UTF-8 마커 샘플 결과는 신뢰하지 않음.
2. **기준선**: 현재 코드로 원본 규칙·진짜 PDF를 돌린 결과를 `484-notes.md`에 기대×실제×일치 표로 기록.
3. **추출**: NFC 정규화, 공백·콜론 정규화, 항목 존재는 줄 순서 비의존. 글자 크기는 pdfjs 텍스트 transform으로 계산(A의 4pt vs 9pt 구분). 못 읽으면 확인 불가(통과 금지).
4. **생성기 비교**: Chromium / LibreOffice(가능 시) / reportlab·pdfkit 등 한글 TTF PDF — 같은 문구 추출 비교를 notes에 기록.
5. **판정**: 오탐·누락(제조번호 LOT 변형, 사용기한 변형, 주소) 수정. 새 규칙 임의 추가 금지. "위반" 단정·내부 id 노출 0.
6. **회귀**: `label-check-483.ts`를 진짜 PDF+추가 생성기 기준으로 갱신, run-all·상세페이지 회귀 불변.
