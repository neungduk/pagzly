# 512차 보고서 — 결과 카드 문제점·수정 구분

## 확인하지 못한 항목
- 실제 브라우저에서 카드 렌더·취소선 유무 육안 확인
- 320/390 뷰포트 실측(가로 스크롤). 정적 CSS 2열→1열 가드만 적용
- 라이브 OCR `partial`일 때 missing 안내 덧붙임 문구 실측

## 종류별 마크업 요약
| 종류 | 문제 | 확인한 내용 | 수정 |
|------|------|-------------|------|
| missing | `"{label}"을(를) 라벨에서 찾지 못했어요.` | 회색 안내(취소선 없음). partial이면 일부 읽음 안내 | **이렇게 넣어 보세요** — 추가할 문구(+복사). 예시 없으면 넣는 방법 |
| wording | `suggest` 또는 라벨 해당 표현 | 문장+걸린 말 빨간·굵게(최대 3+더보기) | **이렇게 고쳐 보세요** — 걸린 말(취소선)→대체(초록) |
| measure | `suggest` 또는 기준 확인 문장 | 읽은 값 / 기준 2열 표(취소선 없음) | **이렇게 확인해 보세요** |
| other | 문제 한 줄 + 기존 내용 | found/evidence | 예시 있을 때만 수정 블록 |

공통: `basis`가 있으면 카드 하단 `기준: {law} — {source}`(접기 없음). 예시 문구 고지 줄은 예시 ≥1일 때만.

## 샘플 결과(`sample-result-a`) 분류
| 종류 | 항목 | found 요약 |
|------|------|------------|
| other | 영업자의 상호 및 주소 | 상호 발췌 + 주소 확인 필요(evidence·checkKey 없음) |
| missing | 제조번호 / 사용기한 / 가격 / 바코드 | `관련 표기를 찾지 못함` |
| measure | 전성분 표시 방법 | `감지된 크기(pt): …` |
| measure | 알레르기 유발성분 25종 표시 | 성분 + `3pt` |
| other | 의약품 오인 우려 표현 금지 | 원문 발췌만 있고 evidence/MFDS 키 없음 |

## `other`로 남은 모호 항목 (다음 차 데이터 보강 후보)
- 영업자의 상호 및 주소 — 발췌는 있으나 evidence 구조 없음 → wording/missing 세분화 후보
- 의약품 오인 우려 표현 금지 — 라이브에 evidence/`MFDS-`가 붙으면 wording으로 재분류됨. 샘플 JSON에는 없음
