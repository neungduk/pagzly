# 485차 목표 (코드 전)

## 성공 기준
1. **업로드 안전**: `%PDF-` 시그니처, ≤10MB, ≤10페이지, 추출 ≤20초, 암호화/손상→열 수 없음(경로·스택 비노출). IP당 분당 10회(메모리; 서버리스 한계는 report).
2. **로그**: 파일명·본문 금지. 응답에 내부 경로·id 0.
3. **글자 없음/부족**: 0자 또는 한글&lt;10자면 판정 중단 + 아웃라인 안내만. 영문만이면 한글 미검출 안내 + 판정 보류. `gen_empty_notext`/`gen_helvetica_nohangul`로 검증.
4. **인쇄**: 선택 제품명·점검일·요약·항목·면책, `@media print` A4 1~2장, 인쇄 버튼, 320/390/750 가로 넘침 0.
5. **회귀**: label-check에 시그니처/11쪽/빈/영문/로그 검사 추가. 상세페이지 코드 미변경.

## 비목표
- 유료 AI/OCR, Production/main, 새 검사 규칙, 상세페이지 변경.
