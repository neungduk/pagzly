## 1. 배경
- 페이지 바탕 #F3F5FB (랜딩 래퍼 범위, 다른 화면의 --lc-bg는 바꾸지 않는다).
- 첫 화면 뒤에 색 번짐 3개(`.wash`): 파랑 #D5DEFF(왼쪽 위 620px), 살구 #FFDCCB(오른쪽 위 560px), 민트 #CFEFE0(가운데 아래 520px). blur 70px, opacity .85, 높이 1250px 영역 안에서만, `pointer-events:none`, `overflow:hidden`으로 가로 스크롤 방지. 이미지 파일 사용 금지(CSS만).
- 번짐은 9s alternate로 30px/24px 천천히 이동. 
- 구간 교차: 히어로·제품 화면 = 번짐 배경 / 어두운 숫자 띠 #111214 / 전·후 구간 흰색 #fff 풀폭 / 마무리 파란 그라데이션 박스(#1D4ED8→#3B5BFF→#6C7DFF, 135deg). 그 외 그라데이션·글로우 추가 금지(스캔 선 제외).
- 대비 4.5:1 유지(색 번짐 위 글자는 #111214/#4A4D54 그대로).

## 2. 움직임
1. 예시 라벨 카드: `rotate(-2.2deg)`, 호버 시 0deg(0.35s), 그림자 `0 30px 70px rgba(40,60,140,.18)`.
2. 떠 있는 칩 2개(라벨 카드 모서리): "고칠 것 1"(왼쪽 위, #D6402B), "확인할 것 2"(오른쪽 아래, #B7791F). 흰 바탕·둥근 14·그림자, 위아래 7px bob(3s / 3.6s, 지연 .6s). **칩 숫자는 데모 데이터(`landing-demo-514.ts`)의 실제 finding 개수에서 계산**해 하드코딩 불일치를 막는다.
3. 형광펜 그리기: 스캔 선이 지나간 뒤 `background-size 0→100%` 0.7s로 순차 표시(고칠 것 1.0s, 확인할 것 1.7s, 사용기한 표기 없음 2.3s). 한 번만 재생.
4. 판정 카드는 514의 순차 fade-up 유지.
5. `prefers-reduced-motion: reduce`이면 번짐 이동·bob·띠 이동·그리기 모두 정지하고 최종 상태(형광펜 100%)로 표시.
6. JS 상태/라이브러리 추가 없이 CSS 애니메이션만. 모든 장식 요소는 `aria-hidden`.

## 3. 문구 띠 (제품 화면과 어두운 숫자 띠 사이)
- 한 줄 가로 흐름(40s linear infinite, 내용 2번 반복해 -50% 이동). 칩: 흰 바탕·선 #E6E6E1·알약, 문구 + 판정 배지(고칠 것 #D6402B / 확인할 것 #B7791F / 문제 없음 #1F7A56, 흰 글자 11px 굵게).
- 내용은 `landing-demo-514.ts`에 모은다. 한국어·영어 문구 섞기(예: 피부 주름을 완전히 없애 주는 / 사용기한 표기 없음 / 내용량 30 ml / 여드름 완치 / 리날룰, 리모넨 포함 / 제조번호 LOT 2411A / Reduces wrinkles permanently / Net Wt. 1 fl oz). **전부 가상 예시**이므로 띠 위나 아래에 "예시 문구입니다" 한 줄 표기. 실제 고객 제품명·상표 사용 금지. 금지어가 문구에 들어가지 않게 하되, 이 데이터는 "걸린 문구 예시"이므로 금지어 검사 대상에서 이 파일의 `before`/`caught` 필드는 제외하지 말고 **대체 문구(`after`)에만 적용**한다(걸린 문구는 의도적으로 문제 표현임을 테스트 주석에 명시).
- 띠에 마우스를 올리면 일시정지(`animation-play-state: paused`). 모바일에서도 동일하게 흐르되 높이 최소화.
