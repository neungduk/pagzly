# 492차 — 검수 정확도 하네스: 변이(결함 주입) 시험 · 표기 변형 시험 · 규칙 커버리지 표

## 0. 규칙
- 유료 호출(AI/OCR)·Production·main 금지. 코드 삭제 금지. **새 검사 규칙을 임의로 만들지 말 것**(규칙표 `review/data/kr_label_rules_draft_v0.1.json`에 없는 판정 금지). 규칙 문구가 모호하면 "확인 필요"로 처리하고 notes에 기록.
- 상세페이지 코드·`/label-check` 화면 문구 변경 금지(필요하면 멈추고 보고). 목표는 `review/492-targets.md`에 코드 전에 기재. 파일은 Read 후에만 Write/Edit. 마무리 전 `npx tsc --noEmit`, `npm run build` 통과. 커밋은 최대 4개.

## 1. 배경
지금까지 검수기는 3개 샘플(A/B/C)과 생성기 몇 종으로만 시험되었다. 실제 고객 시안은 표기 방식이 훨씬 다양하다(예: 사용기한 `2028.10.31까지`/`EXP 2028-10-31`/`개봉 후 12M 심벌`, 내용량 `150 ml`/`150㎖`/`100g`, 제조번호 `Lot.`/`LOT No.`/`L/N`, 주소 표기 여러 형태, 2단 배치·글상자 순서 뒤섞임). **빠진 것을 놓치는 것(누락)** 과 **있는데 없다고 하는 것(오탐)** 이 모두 신뢰를 깎는다. 이 차수는 이를 체계적으로 측정하고 고친다.

## 2. 항목
### A. 규칙 커버리지 표 (읽기 전용 → `review/492-coverage.md`)
- 규칙표 35개 전부에 대해: id(내부용, 문서에만) / 제목 / 규칙의 check_type(code·ai·manual) / **현재 구현 상태**(자동 판정 / 부분 판정 / 수동 확인 목록만 / 미구현) / 근거 파일·함수 / 한계. 화면 노출용이 아니므로 id 사용 가능.
- "code인데 미구현/부분"인 규칙 목록을 맨 위에 정리 → 이번 차수 수정 대상.

### B. 변이(결함 주입) 시험 하네스
- `scripts/label-check-mutation-492.mjs`(또는 ts): 기준 정상 시안(샘플 C 계열 텍스트)을 코드로 PDF 생성(Playwright `page.pdf`, 한글 폰트 임베드)하고, **항목 하나씩 제거/손상**한 변이본을 자동 생성: 명칭·상호·주소·용량·사용기한·제조번호·제조국·전성분·주의사항 각각 제거, 전성분에서 알레르기 성분(리모넨 등) 제거 또는 글자 크기를 4pt로, 기능성 체크 시 기능성 문구 제거, 금지 키워드 주입 등.
- 기대: 제거한 항목은 "위반 가능/확인 필요"로 잡히고, **나머지 항목은 통과 상태 유지**(다른 항목에 번지는 오탐 0). 결과를 표(변이 × 기대 × 실제)로 `review/492-notes.md`에 기록하고 `scripts/regression/label-check-492.ts`로 회귀화.

### C. 표기 변형 시험 (정상인데 오탐 나는지)
- 같은 정상 의미를 다른 표기로 쓴 변형본을 항목별 최소 5개씩 생성해 모두 "통과"여야 한다. 예: 사용기한 `사용기한: 2028.10.31까지` · `2028-10-31` · `EXP. 2028.10` · `제조일로부터 36개월` · `개봉 후 12개월(M 심벌 병기)`; 용량 `150mL` · `150 ml` · `150㎖` · `100g` · `50 mL (1.69 fl. oz.)`; 제조번호 `제조번호: LOT123` · `Lot.No 123` · `L/N: A123` · `LOT: 2411A`; 영업자 `화장품책임판매업자: (주)○○ 서울특별시 …` · `책임판매업자 ○○ / 주소 …` · `판매원: …`(규칙 문구에 근거가 있는 것만); 전성분 `전성분` · `성분` · `Ingredients`(규칙표에 근거 있는 것만, 없으면 확인 필요 처리하고 notes에 기록).
- **글자 순서·배치 변형**: 2단 레이아웃, 글상자 순서 뒤섞임, 줄바꿈으로 항목 이름과 값이 떨어진 경우. 순서에 의존하지 않고 판정되어야 한다.
- 실패하는 변형은 판정 로직의 패턴/정규화를 고쳐서 통과시키되, 규칙 근거 없이 느슨하게 만들지 말 것(느슨해지면 누락이 늘어나므로 B의 변이 시험도 같이 통과해야 한다).

### D. 글자 크기·알레르기 정밀화
- 5pt 미만 판정: 전성분 영역 글자를 항목별로 따로 측정(영역 식별이 불가하면 "확인 불가", 통과 금지). 경계값(4.9/5.0/5.1pt) 시험 포함.
- 알레르기 25종: 한글명·INCI 영문명 모두 매칭(`allergens-kr-25_draft.json`, 한글명 미검증 표시는 화면에 유지). 전성분에 `향료`만 있고 알레르기 성분이 없는 경우, 알레르기 성분이 있고 `향료`가 없는 경우, 둘 다 있는 경우를 구분해 문구가 맞는지 확인(함량 임계값 자동 판정은 불가 → 확인 필요).

### E. 판정 보정
- "위반 가능"(필수 항목이 없는 것으로 보임)과 "확인 불가"(글자를 못 읽거나 근거 부족)의 기준을 `review/492-notes.md`에 표로 정리하고, 현재 코드가 그 기준대로인지 시험으로 확인. 글자가 거의 안 읽히는 PDF에서 "위반 가능"이 쏟아지지 않아야 한다.
