# 494차 — ① 한국 오탐 수정 ② "수정 제안" 기능 ③ 미국 시장 모드

## 0. 규칙
- 유료 호출·Production·main 금지. 코드 삭제 금지. 상세페이지 코드 변경 금지. "위반" 단정 금지. 규칙 근거 없는 판정 신설 금지.
- 목표를 `review/494-targets.md`에 코드 전에 기재. Read 후 Write/Edit. 마무리 전 `npx tsc --noEmit`, `npm run build`. 커밋 최대 4개. 보고서 `review/494cha-report.md`.
- **"완벽 검수"·"자동 수정 보장" 표현을 화면·문서 어디에도 쓰지 말 것.** 화면은 "사전 점검 + 수정 제안"으로만.

## 1. 한국 오탐 수정 (493차 D 조사 결과 반영)
- `"향"` 단독 패턴이 주소 `향남읍`에 매칭되어 정상 시안 i1에서 알레르기 항목이 뜬다. 규칙 데이터는 바꾸지 말고 **로직**에서 단독 한 글자 패턴은 단어 경계(앞뒤가 한글이 아닌 경우 또는 `향료` 같은 완결 어휘)로 제한. i1에서 알레르기 항목이 사라지는 회귀 시험 추가. 다른 한 글자 패턴이 있는지 데이터 전수 점검 후 notes 기록.

## 2. "수정 제안" 기능 (한국·미국 공통)
- 목적: 확인 필요 항목마다 **어떻게 고치면 되는지 문구 제안**을 보여 준다. PDF 자체를 자동 수정하지 않는다(디자인 파일은 사용자가 고침).
- 데이터에서만 가져온다: 미국 규칙은 `fix_ko`/`fix_example_en`이 있다. 한국 규칙표(`kr_label_rules_draft_v0.1.json`)와 `ad-phrases`에는 해당 필드가 없다 → **데이터 파일에 직접 쓰지 말고** `review/data/fix-suggestions-kr_todo.md`에 "수정 제안이 필요한 한국 규칙 id 목록"만 만들어 보고(작성은 기획 담당). 우선 규칙표의 기존 `how_to_fix` 류 필드가 있으면 그것을 사용.
- 화면: 각 항목 아래 "수정 제안" 접힘 영역 1개. 예시 문구는 "예시이며 그대로 사용하지 말고 실제 정보로 바꾸세요" 한 줄 동반. 광고 표현은 "완화 표현 예시" + "근거 자료 확인" 안내까지만.
- 결과 맨 아래 "수정 제안 모아 보기"(텍스트 복사 버튼). 서버 저장 없음 유지.

## 3. 미국 시장 모드
- 입력: 시장 선택(한국/미국) — 기본 한국. URL 쿼리 또는 화면 토글. 미국 선택 시 `review/data/us_label_rules_draft_v0.1.json` 사용(기획 담당 작성, 레포에 있음). 필드가 한국과 다르므로 **로더를 시장별 어댑터로 분리**.
- 미국 판정(코드 가능한 것만): US-002 정체성 단어, US-003 내용량(fl oz/oz/mL/g 숫자 동반), US-004 'Distributed by' 등 + 주 약어+ZIP 패턴, US-006 'Ingredients' 제목과 성분 구간(영어 성분은 콤마 구분), US-007 한글만 있는 라벨 감지, US-010 전화/이메일, US-013 의약품 주장 영어 표현. 나머지(`manual`)는 "확인 필요 질문" 카드로 표시.
- 추가 입력(체크박스): 수입품 여부(US-005), 전문가용(US-011), 에어로졸/아동용 등 위험 제품(US-009), 자외선차단·여드름 등 **OTC 의약품 성격**이면 안내 "이 점검기는 일반 화장품만 다룹니다(OTC 약품은 Drug Facts 라벨 별도)" 표시하고 판정 보류.
- 영어 텍스트 처리: 대소문자 무시, 줄바꿈 하이픈 합치기. 글자 크기 판정(1/16 inch = 4.5pt 근사)은 폰트 크기 추출이 될 때만 "확인 필요"로, 불가 시 "확인 불가". 단위 환산식은 `review/494-notes.md`에 근거 기록.
- 결과 요약·면책: 미국 모드 면책 문구에 "미국 연방 규정 기준이며 주(州) 법(예: 캘리포니아)은 포함되지 않음" 추가. 새 카피는 이 한 줄과 시장 선택 라벨 외 만들지 말 것.
- 시험 픽스처: 미국 영문 시안 3개를 **Cursor가 만들지 말고** 기획 담당이 495차에 제공. 이번 차수는 코드 + 합성 텍스트 단위 시험(문자열 주입)으로 US-002/003/004/006/010 정상·누락 케이스 각 1개 이상.
