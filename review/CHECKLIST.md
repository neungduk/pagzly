# 상세페이지 품질 체크리스트 (v4 — 디자인 시스템 v1 + 화질보정/배경생성 파이프라인 v2 반영)

Claude Code가 스크린샷(review/attempt-N.png)을 보고 이 기준으로 통과/실패를
판단합니다. 이 파일은 계속 직접 고쳐가면서 다듬으세요.

## 필수 항목 (하나라도 실패하면 FAIL, 다음 반복으로)

- [ ] **배경/강조색이 카테고리 고정색이 아니라, 실제 업로드된 상품 사진의
      색상(제품 자체 색, 패키지 색, 브랜드 톤)에서 뽑아낸 색이다.**
      예: 같은 "화장품/뷰티" 카테고리라도 상품이 파란 젤 크림이면 배경도
      청록/블루 계열로, 상품이 코랄색 립스틱이면 배경도 그에 맞게 달라져야
      한다. "카테고리=화장품이니까 무조건 청록"처럼 고정되어 있으면 FAIL.
- [ ] 히어로 섹션 헤드라인 텍스트가 배경 사진과 겹쳐서 읽기 어려운 부분이 없다
- [ ] 모든 이미지가 찌그러지거나 비율이 깨지지 않고 정상적으로 보인다
- [ ] 섹션이 최소 6개 이상 채워져 있다 (텅 빈 섹션이나 "undefined" 같은 텍스트 없음)
- [ ] 사진 배경이 단색 그라데이션이 아니라 실사 느낌 스튜디오 배경이다
- [ ] 텍스트가 카드/섹션 밖으로 삐져나오거나 다른 요소와 겹치지 않는다
- [ ] (화장품 카테고리인 경우) "치료", "완치", "제거" 등 식약처 금지 표현이 안 보인다
- [ ] (식품 카테고리인 경우) "치료", "예방", "효능" 등 과장/의약품 오인 표현이 안 보인다
- [ ] 가격이 정상적으로 표시된다 (₩0, undefined, NaN 등이 아님)

## 디자인 시스템 v1 체크 (lib/design-tokens.ts 기준)

- [ ] **페이지 전체에서 색이 accentColor / baseNeutral / deepAccent 3종만
      순환 사용된다.** 섹션마다 새로운 배경색이 임의로 생기지 않았는지 확인.
      (홀수 번째 본문 섹션 = baseNeutral 단색 / 짝수 번째 = accentColor 옅은 단색,
      hero만 예외적으로 accentColor 그라데이션 허용)
- [ ] 장식용 도형(원, 블롭 등)이 hero 섹션 외에는 전혀 없다. hero에 있더라도
      accentColor 8~12% 투명도이고, 상품 사진 위로 겹쳐서 시선을 끌지 않는다
- [ ] 섹션 순서가 카테고리 템플릿(lib/section-templates.ts)의 고정 슬롯
      순서와 일치한다 (임의로 섹션을 추가/재배열/생략(선택 슬롯 제외)하지 않았다)
- [ ] 갤러리/다각도 컷처럼 여러 장을 나란히 쓰는 슬롯의 사진들이 같은 비율·같은
      촬영 톤으로 통일되어 있다 (한 장만 다른 배경 톤이면 FAIL)
- [ ] 상품 라벨/브랜드 텍스트가 이미지 crop으로 잘리지 않았다
- [ ] 헤드라인이 2줄, 본문 설명이 3줄을 넘지 않는다 (line-clamp 적용 확인)

## 화질 보정 / 배경 생성 파이프라인 체크 (v2 — clarity-upscaler + flux-fill-dev)

`lib/photo-enhance.ts` 파이프라인이 851-labs(배경 제거) → clarity-upscaler
(화질 보정) → flux-fill-dev(배경 생성, 상품 색상 반영) → 배경 합성 순서로
바뀐 뒤 추가된 체크 항목. 필수 항목 판단 시 위 항목들과 동일하게 취급한다.

- [ ] 상품 사진이 원본 대비 흐릿하거나 노이즈/블록 깨짐이 없고, 디테일
      (질감, 로고, 인쇄 텍스트)이 뭉개지지 않고 또렷하다 (clarity-upscaler
      보정 확인)
- [ ] 보정 과정에서 상품의 색상·형태·로고·텍스트가 원본 사진과 달라지지
      않았다 (업스케일러가 디테일을 "창작"해 원본과 다른 무늬/글자를
      만들어내지 않았는지 원본과 나란히 비교)
- [ ] 배경이 카테고리 고정 그라데이션이 아니라 flux-fill-dev가 생성한 실사
      스튜디오 배경이고, 그 톤이 상품 사진에서 뽑은 accentColor/baseNeutral과
      자연스럽게 어울린다 (예: 상품이 노란빛이면 배경도 그에 맞는 웜톤)
- [ ] 상품과 배경의 합성 경계선이 부자연스럽게 잘려 보이거나 이중 그림자/
      색 번짐이 생기지 않았다
- [ ] (보정/배경 생성 API가 실패한 경우) 원본 이미지 또는 보정 전 컷아웃으로
      정상 폴백되어 상세페이지 생성 자체가 막히지 않았다 — 서버 로그의
      `[sharpenCutout]`/`[generateBackdrop]` 경고로 실제 폴백 여부 확인
- [ ] 서버 로그에 `[cost] generateBackdrop`, `[cost] enhanceProductImage`,
      `[cost] generateCopyWithDeepSeek`, `[cost] product=...` 4줄이 정상
      출력되고, `products.generation_cost` 값이 0이나 NaN이 아니라 저장된다

## 품질 목표 참고 기준 (합격선이 아니라 방향성 참고용)

아래는 글로이스트(glowiest.co.kr) 브랜드 상세페이지 수준을 참고 기준으로 삼되,
**전문 촬영/브랜드 전용 일러스트까지 똑같이 따라갈 순 없으니, 이 방향에
"가깝게" 가는 걸 목표로 판단해줘:**

- 상품 고유의 색감이 페이지 전반(배경, 강조색, 배지 색 등)에 일관되게 반영됨
- 섹션이 단조롭지 않고, 사진+텍스트 배치가 번갈아 가며 리듬감이 있음
- 히어로 사진이 상품을 실제로 사용하는 느낌(손에 든 컷, 클로즈업 등)으로
  보이면 더 좋음 (원본 업로드 사진 중 그런 사진이 있을 경우에 한함)
- 빈 여백이 어색하게 크게 남지 않음

## 선호 항목 (있으면 좋음, 없어도 FAIL 아님 — 참고용 메모만)

- [ ] 헤드라인이 구체적이고 상투적이지 않다 ("최고의 상품입니다" 같은 문구 지양)
- [ ] 성분/스펙표가 있는 카테고리는 표가 깔끔하게 정리되어 있다

## 판단 기준

- 필수 항목 전부 통과 → **PASS**, 반복 종료
- 필수 항목 중 하나라도 실패 → **FAIL**, 원인이 될 코드를 찾아 구체적으로
  수정 후 재시도.
  - 색상 관련 실패라면 `lib/design-tokens.ts`(3색 규칙)와
    `lib/color-extract.ts`(baseNeutral/deepAccent 추출)를 먼저 확인.
  - 섹션 순서/종류 관련 실패라면 `lib/section-templates.ts`의 카테고리
    템플릿과 `app/api/generate/route.ts`의 슬롯 정규화(`normalizeSectionsToTemplate`)를
    먼저 확인 — AI가 슬롯을 새로 만들거나 순서를 바꿨을 가능성.
  - 이미지 비율/crop 관련 실패라면 `lib/design-tokens.ts`의
    `SLOT_IMAGE_RATIO`와 `components/DetailSectionRenderer.tsx`의
    `resolveImageRatioClass`를 먼저 확인.
- 5번 반복해도 통과 못 하면 → 중단하고 어떤 항목이 계속 실패하는지 요약 보고
