# 상세페이지 품질 체크리스트 (v2)

Claude Code가 스크린샷(review/attempt-N.png)을 보고 이 기준으로 통과/실패를
판단합니다. 이 파일은 계속 직접 고쳐가면서 다듬으세요.

## 필수 항목 (하나라도 실패하면 FAIL, 다음 반복으로)

- [ ] **배경/강조색이 카테고리 고정색이 아니라, 실제 업로드된 상품 사진의
      색상(제품 자체 색, 패키지 색, 브랜드 톤)에서 뽑아낸 색이다.**
      예: 같은 "화장품/뷰티" 카테고리라도 상품이 파란 젤 크림이면 배경도
      청록/블루 계열로, 상품이 코랄색 립스틱이면 배경도 그에 맞게 달라져야
      한다. "카테고리=화장품이니까 무조건 청록"처럼 고정되어 있으면 FAIL.
- [ ] 히어로 섹션 헤드라인 텍스트가 배경 사진과 겹쳐서 읽기 어려운 부분이 없다
- [ ] 모든 이미지가 찌그러지거나 비율이 깨지지 않고 정상적으로 보인다
- [ ] 섹션이 최소 6개 이상 채워져 있다 (텅 빈 섹션이나 "undefined" 같은 텍스트 없음)
- [ ] 사진 배경이 단색 그라데이션이 아니라 실사 느낌 스튜디오 배경이다
- [ ] 텍스트가 카드/섹션 밖으로 삐져나오거나 다른 요소와 겹치지 않는다
- [ ] (화장품 카테고리인 경우) "치료", "완치", "제거" 등 식약처 금지 표현이 안 보인다
- [ ] 가격이 정상적으로 표시된다 (₩0, undefined, NaN 등이 아님)

## 품질 목표 참고 기준 (합격선이 아니라 방향성 참고용)

아래는 글로이스트(glowiest.co.kr) 브랜드 상세페이지 수준을 참고 기준으로 삼되,
**전문 촬영/브랜드 전용 일러스트까지 똑같이 따라갈 순 없으니, 이 방향에
"가깝게" 가는 걸 목표로 판단해줘:**

- 상품 고유의 색감이 페이지 전반(배경, 강조색, 배지 색 등)에 일관되게 반영됨
- 섹션이 단조롭지 않고, 사진+텍스트 배치가 번갈아 가며 리듬감이 있음
- 히어로 사진이 상품을 실제로 사용하는 느낌(손에 든 컷, 클로즈업 등)으로
  보이면 더 좋음 (원본 업로드 사진 중 그런 사진이 있을 경우에 한함)
- 빈 여백이 어색하게 크게 남지 않음

## 선호 항목 (있으면 좋음, 없어도 FAIL 아님 — 참고용 메모만)

- [ ] 헤드라인이 구체적이고 상투적이지 않다 ("최고의 상품입니다" 같은 문구 지양)
- [ ] 성분/스펙표가 있는 카테고리는 표가 깔끔하게 정리되어 있다
- [ ] 섹션 순서가 자연스럽다 (히어로 → 특징 → 상세설명 → 사용법 → 주의사항 순서 등)

## 판단 기준

- 필수 항목 전부 통과 → **PASS**, 반복 종료
- 필수 항목 중 하나라도 실패 → **FAIL**, 원인이 될 코드를 찾아 구체적으로
  수정 후 재시도. 특히 색상 관련 실패라면, `lib/category-theme.ts`가
  "카테고리별 고정 팔레트" 구조라는 게 근본 원인일 수 있음 — 이 경우
  카테고리 고정 색 대신 **상품 사진에서 색을 직접 추출하는 방식으로
  구조 자체를 바꿔야 할 수도 있다는 걸 인지하고 판단할 것.**
- 5번 반복해도 통과 못 하면 → 중단하고 어떤 항목이 계속 실패하는지 요약 보고
