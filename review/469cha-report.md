## 5. 일반 섹션: 변환한 것·못 한 것
- 변환: **target_persona**(concern 계열, 3~6개·각 40자 이하·사진 띠 없음. 사진 띠가 있는 5개는 사진이 사라지므로 기존 렌더러 유지), **step_card**(benefits.zigzag, 2~4단계·단계 사진 모두 유효·중복 없음), **상품 정보 표**(DOM 유지, CSS로 ledger/stack 구조).
- 못 한 것과 사유: 상품 정보의 "짧은 값은 큰 숫자 카드" — 값 길이는 CSS로 구분할 수 없고 spec_table에는 크기 비교·부피·식품 비율·소음·방수·무게·소비전력 도식과 썸네일이 붙어 있어 단일 소스로 옮기면 도식이 사라진다(도식 판정 함수 전부 재사용 필요, 시간·크기 상한 사유로 미착수). review_highlight(집계·고지 문구 위치), checklist·tradeoff_card·comparison_chart(비교 정책·수치 게이트), color_variation(색상 선택 인터랙션)은 정책·인터랙션 사유로 기존 렌더러 + 래퍼 다이나믹.
- 동작 확인: 모든 추천 대상 문장·단계 제목/본문이 V5 출력에 그대로 있다(회귀, 태그 제거 후 텍스트 비교).

## 6. 정직한 한계
- 지표는 문자열 대리 지표다(추정 높이·min-height 선언). **눈 검수 전**이라 정보 구간 밝기, 본문 크기, 장면의 과다 여부를 모른다.
- 정보 구간 덮어쓰기는 문서 CSS 순서(infoCss·designV2Css 뒤에 archetype CSS가 놓임)에 의존한다.
- 장면 평균 미달은 섹션 9개짜리 희소 입력 3페이지가 후보를 못 채워서다(그 3페이지는 0개). 장면 후보 종류(story·phototext·stats·statement)를 늘리지 않았다.
- `v5-466`의 변형 선호 회귀는 장면 승격(별도 단계)을 끄고(`setScenesOffForTests`) 선호 규칙만 본다. 기준을 낮추지 않았다.
- 소스 정정: 468차 보고의 읽히는 초점 계산은 CSS처럼 마지막 font-size 선언을 쓰도록 고쳤다(`typeCss`가 기본 크기 뒤에 덮어쓰기를 붙이는 곳이 있음; 값은 변화 없음).
