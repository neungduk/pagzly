대상(합성 픽스처 5종, export, 실제 Noto Sans KR): 뷰티 `fx-compare-beauty` · 패션 `fx-tier-rich-fashion-6p` · 테크 `fx-tier-rich-tech-6p` · 생활 `fx-tier-normal-living-3p` · 빈약 입력 `fx-tier-sparse-beauty-1p`.
본 것: 390px 첫 3화면(`*-first3-390.png`) + 750px 전체 페이지(`*-full-750.png`, 3000px 단위로 잘라 가로로 나열·축소). `*-first3-390.png`·`*-full-750.png`는 **번호 수정 전** 캡처(관찰 근거)이고, 수정 후는 `beauty-after-first3-390.png`·`tech-after-first3-390.png`(01 POINT → 02 CHECK → 03 STORY). 사진은 합성 자리표시자라 **사진 자체의 품질은 판단하지 못했다**(PC에서 실사로 확인 필요).
