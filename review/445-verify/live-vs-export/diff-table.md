# 라이브 ↔ export 차이 표 (445차 1)

도구: `scripts/live-vs-export.ts`(섹션 단위 숫자 대조) · `scripts/live-capture.ts`(라이브 화면 캡처).
입력: 합성 픽스처 21종 × 390px(+6종 × 750px). 라이브는 더미 환경값으로 띄운 `next dev`의 `/dev/detail-preview?capture=session`.
짝지은 섹션 수(최상위 `<section>`): 390px 21종 모두 export = 라이브 섹션 수 일치, 750px 6종도 일치.

## 측정 함정 (차이가 아닌 것)
| 현상 | 원인 | 처리 |
|---|---|---|
| 라이브 섹션이 6~6.5% 좁고 낮게 측정됨(예: 367/390) | 섹션 진입 gsap `scale 0.94→1`(약 1초)이 끝나기 전에 측정 | 캡처 도구가 `[data-scroll-reveal]`을 끝 상태로 고정하고 1.5초 대기 |
| 개발 미리보기만 구성이 달라 보임 | 개발 미리보기는 표시 예산·`chartRemoved`를 적용 안 함 | `live-lib.ts`가 같은 예산을 미리 적용해 preset으로 전달 |
| 라이브 섹션 첫 글자가 `COMPARE`·`INFO`·`PRICE`(눈썹 라벨) | 라이브는 라벨이 글자로 보임 | 짝 서명에서 선행 대문자 라벨 제외 |
