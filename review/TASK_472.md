## 1. 기획 담당이 471차를 직접 렌더해서 본 판정

장식 숫자 겹침, 사진 하한, 짧은 구분 띠는 의도대로 들어갔고 가로 넘침 0.

가장 큰 문제: 첫 화면이 "지표로는 다른데 눈으로는 같다". 키보드 픽스처로 8종을 나란히 본 결과 catalog / softlife / pop 세 개가 똑같은 파란 배경 + 왼쪽 위 제목 + 큰 사진 카드 + 흰 테두리 구성이다. 쌍 시그니처 "3칸 차이"는 토큰(정렬·순서 이름)만 세서 이런 경우를 못 잡는다. impact도 같은 구성의 검은 버전에 가깝다.

파란 배경은 상품과 상관없이 한 색이다(키보드는 파랑, 스킨케어/원피스는 다른 색이어야 자연스러운데 아키타입 색이 우선이라 상품 분위기가 안 따라온다).

## 2. 이번 라운드 항목

### A. 첫 화면 "눈으로 다름" 강제 (최우선)

지표 재정의: `hero-metrics-472.ts`에 시각 시그니처를 추가한다. 항목: 히어로 배경 색상 계열(hue 구간 6개로 양자화 + 명도 3단계), 제목 정렬(좌/중/우), 제목 위치(사진 위/겹침/아래/옆), 사진 틀 모양(풀블리드/카드/원/아치/분할), 사진 면적 비율, 가격 표시 방식(칩/큰 글자/스티커/인라인), 한눈에 보기 형태(행/칩 스크롤/큰 숫자/카드). 8종 쌍마다 이 7개 중 4개 이상 달라야 통과(자동 테스트, 지표 정의를 완화하지 말 것).

지금 같은 구성인 catalog / softlife / pop / impact를 서로 확 다르게 다시 짠다. 예시 방향(자유 재설계 허용, 하드 규칙만 지키면 됨):

- catalog: 흰 바탕 + 사진 좌/정보 우 분할, 스펙 칩 줄
- softlife: 파스텔 + 둥근 아치 사진 + 겹친 둥근 가격 카드
- pop: 원색 대비 + 사진을 기울인 스티커 틀 + 가격 별 배지, 한눈에 보기 가로 스크롤 칩
- impact: 풀블리드 사진 위 거대 제목(56px+) + 어두운 그라데이션 + 큰 가격 숫자

히어로 색을 상품 분위기에 따라 정한다: 기존 상품 팔레트/브랜드 색 추출 로직이 있으면 재사용하고, 아키타입 색은 보조(액센트)로 낮춘다. 아키타입 8종이 같은 상품에서 최소 5가지 서로 다른 히어로 색 계열을 내야 한다. 새 색 추출 코드를 쓰면 로컬 SVG/데이터 URL만으로 동작해야 한다.

하드 규칙 유지: 가격·필수 고지·구매 위치/문구 불변, fold 규칙, 사진 실패 시 제목 카드 폴백, 탭 칩 앵커 기능 불변, 사진 폭 하한.
