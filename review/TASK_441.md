## 1. 항목 (항목마다 커밋 1개)

### 1-1. 섹션 제목 시스템 통일 (`lib/type-treatments.ts` 확장)
- 현재 모든 섹션 제목(h2급)의 **굵기·크기·색·자간·정렬**을 DOM으로 전수 수집해 표(`review/441-verify/heading-audit.md`) — 제목 스타일이 몇 종 쓰이는지, 어느 섹션이 얇고 연한 스타일인지.
- mood별 **제목 프리셋 3종**(예: ① 굵은 큰 제목 + 작은 영문/번호 라벨 ② 라벨 알약 + 제목 ③ 중앙 정렬 제목 + 짧은 밑줄 모티프)을 정의하고 **모든 섹션 제목이 프리셋 하나를 따르게**: 굵기 700 이상(주요 제목 900), 크기 위계 3단(대 26~30 / 중 20~22 / 소 16~18), 색은 면 역할 대비 4.5:1 이상의 진한 톤 + 키워드만 포인트 색. 얇은 연한 제목은 폐기(굵기 400대 h2 0건).
- "이런 고민 있으신가요?" 같은 질문 제목은 크기·굵기를 맞추고 `Q.` 라벨 알약으로 처리해도 됨(문구는 그대로).
- 린터 신규 규칙 **R16(제목 위계)**: 굵기 <600 제목, 같은 크기 위계 역전, 한 페이지 제목 스타일 종류 >3 → warn/error. 회귀 추가.

### 1-2. 이전 정보 섹션 디자인 언어 (표·FAQ·주의·배송·고지)
- 439·440에서 미룬 항목. `hardcode-list.md`의 하드코딩을 **섹션 단위로 토큰 치환**(행간·반경·그림자·색): 표는 헤더 면 + 줄무늬 면 역할, FAQ는 카드형(Q 번호/아이콘 + 답, 정적 펼침), 주의·고지는 얇은 면 + 아이콘 + 12~13px 하한 유지.
- **전부 안내 문구인 배송 표**(결정 위임): 행이 모두 안내 문구면 카드 반복 대신 **한 장의 압축 안내 카드**(아이콘 + 문구 2~4줄 목록, 입력 문구 원문)로 합쳐 표시. 일부만 안내 문구면 현재 방식. 값 행은 그대로 표.
- 섹션 전/후는 **캡처를 이 섹션들에서만**(저장 세션 3종, 해당 섹션만 잘라 한 장, 5분 상한).

### 1-3. 고스트 글자·오버레이 충돌 규칙
- 어두운 면 위 오버레이 카드, 사진 위 텍스트 카드가 있는 **임팩트 블록에서는 고스트 글자를 끄거나 카드 영역 밖으로 마스킹**(좌표 모델 기반 안전 영역 계산을 히어로뿐 아니라 임팩트 블록에도 적용). 린트 R9(모티프-글 겹침)를 고스트 글자까지 확장해 회귀에 추가.

### 1-4. 경계·깊이·숫자 컴포넌트 (440 미적용 7-1~7-3)
- **경계 구분선 6종**: 물결·사선·톱니·점선·이중선·그라데이션 페이드(SVG/border/gradient만), mood별 기본 2종, 면 전환마다 칼 같은 직선 대신 선택(428 면 반전 예산 영향 없게 면 색은 불변).
- **카드 깊이 토큰**: 그림자 3단계(없음/은은/떠 있음) + hairline 테두리 토큰을 만들어 v4 카드 전부 한 토큰 세트로(`rg`로 박스 그림자 하드코딩 목록화 후 v4 치환).
- **숫자 강조 컴포넌트 통일**: 큰 숫자 + 작은 단위 + 라벨(예: 30 mL, 4가지, 15cm)을 한 컴포넌트로, 숫자는 424 게이트 통과 값만, 값 전체 한 줄 폭 맞춤(`statFitEm` 재사용), 칩/스트립/큰 숫자/스펙 카드가 공유.

### 1-5. 구매 직전 신뢰 스트립 + 후킹 마감
- 입력에 있는 **배송·교환/반품·보증·결제·인증 문구**를 아이콘(440 아이콘 세트)과 함께 한 줄/2×2 신뢰 스트립으로 모아 하단 구매 접점 바로 위에 배치(입력 없으면 생략, 억지 아이콘 금지). 스티키 구매 바와 톤 일치, 라이브·export 같은 마크업.
- 구매 접점 카드: 제품명 + 가격(통화기호 작게) + 핵심 혜택 1줄 + 신뢰 스트립 순서로 시선 흐름 정리. 새 문구·할인율 계산 금지.

### 1-6. 간격 리듬 린트 (DOM)
- DOM 측정 기반 **R17 세로 리듬**: 섹션 상하 패딩이 3단 스케일(조밀/보통/여유)에서 벗어나는 값, 인접 섹션 패딩 급변, 한 화면 안 요소 간격 불균형을 감지. 벗어난 값은 v4에서 스케일로 스냅.
- 린트 24종 재채점(평균·최저 전/후), 규칙 R16·R17 포함.

1. 본문 사진 톤 통일 오버레이(mood별 은은한 틴트, export/PNG 동작 확인).
