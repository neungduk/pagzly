## 4. 4.5 미만·다음 브리프 후보 (수정하지 않음)

1. **히어로 워드마크 대비** — 상단 비그라디언트 구간 + 밝은 히어로 컷 (전 카테고리 공통 구조).  
2. **식품 크기비교 다이어그램 선/라벨 대비** — 골드 온 크림.  
3. **58 픽스처 정보 정합** — living/pet이 화장품 섹션·카피 재사용; fashion/food/electronics도 뷰티 이미지. 통합 QA의 **카테고리 전용 픽스처** 없으면 「정보」가 구조적으로 4.5를 못 넘김.  
4. **생활용품 패턴 공백** — `CATEGORY_PATTERN_SVG`에 키 없음.  
5. **세리프 제목↔고딕 다이어그램** — 버그라기보다 위계 의도. 다만 패션 사이즈 블록에서 톤 점프가 가장 큼 → 완화 여부는 정책 결정.
