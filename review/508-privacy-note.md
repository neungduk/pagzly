# 508 — 개인정보처리방침에 넣을 항목 목록(초안·전문가 검토 대상)

> `/privacy` 본문은 이번 차수에서 수정하지 않음. 아래는 넣을 항목 체크리스트만.

1. **처리 목적**: 화장품 라벨·광고 문구 사전 점검을 위해 사용자가 올린 이미지/PDF에서 글자 추출(OCR).
2. **수탁자**
   - 한국 판매 선택: 네이버클라우드(CLOVA OCR).
   - 미국 판매 선택: Google LLC (Cloud Vision). 한국에서 CLOVA 미설정 시 Google로 대체 가능(구현 동작).
3. **국외 이전**: Google 경로만 미국 등 처리 지역으로 이미지 조각이 전송될 수 있음(전문가 확인).
4. **이전 항목**: OCR 요청의 이미지 조각(JPEG base64). 원본 파일명·계정 식별자를 OCR 본문에 넣지 않음.
5. **보관**: OCR 원본·응답 원문·추출 전문 **미저장**. 월 사용량 카운터(`YYYY-MM:google` / `YYYY-MM:clova`)만.
6. **보유 기간**: 전송 후 즉시 폐기(서버 미보관). 카운터는 과금 보호용 숫자만.
7. **거부·대안**: 키 없음·한도 초과 시 문구 붙여넣기.
8. **고지 UI**: 시장별 수탁자 이름 + 버튼명 “외부 전송”.
