# 508 — 개인정보처리방침에 넣을 항목 목록(초안·전문가 검토 대상)

> `/privacy` 본문은 이번 차수에서 수정하지 않음. 아래는 넣을 항목 체크리스트만.

1. **처리 목적**: 화장품 라벨·광고 문구 사전 점검을 위해 사용자가 올린 이미지/PDF 쪽 화면에서 글자를 추출(OCR).
2. **수탁자**: Google LLC (Google Cloud Vision API).
3. **국외 이전**: 미국 등 Google 처리 지역으로 이미지(조각)가 전송될 수 있음.
4. **이전 항목**: OCR 요청에 포함된 이미지 조각(JPEG base64). 원본 파일명·계정 식별자를 Vision에 보내지 않도록 구현.
5. **보관**: Pagzly 서버에 OCR 원본 이미지·Vision 응답 원문·추출 전문을 **저장하지 않음**. 월 사용량 카운터(조각 수)만 집계.
6. **보유 기간**: 전송 후 OCR 처리 즉시 폐기(서버 미보관). 사용량 카운터는 과금 보호 목적의 월 단위 숫자만.
7. **거부·대안**: OCR 키 미설정·한도 초과·사용자 미사용 시 문구 붙여넣기 점검으로 대체.
8. **고지 UI**: 버튼명에 “외부 전송” 명시 + 전송 안내 한 줄(동의 체크박스 없이 안내).
