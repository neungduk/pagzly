# 497차 — 미국 실 PDF 시험 + 이미지 PDF 처리 + 미국 오탐 점검

## 0. 규칙
- 유료 호출(OCR·AI) 금지. Production·main 금지. 코드 삭제 금지. 규칙 데이터 파일 수정 금지(수정 필요하면 보고). "위반" 단정·"완벽/보장" 금지.
- `review/497-targets.md`에 코드 전 기재. 마무리 전 `npx tsc --noEmit`, `npm run build`. 커밋 최대 3개. 보고서 `review/497cha-report.md`.

## 1. 미국 PDF 시험 (기획 담당이 만든 4개: `review/data/samples/us-497/`)
`scripts/regression/label-check-497.ts`에 고정 기대값으로 등록하고 미국 모드(market=US)로 실행:
| 파일 | 내용 | 기대 |
|------|------|------|
| us1_ok | 정상 영문 라벨(내용량·Distributed by+주소·Ingredients·연락처·Made in Korea) | possible 0 (수입품 체크 시 원산지 통과). 의약품 주장 확인 필요 0 |
| us2_missing | 내용량·Ingredients·주소·연락처 없음, 치료·영구 재생·줄기세포·임상 입증 문구 | 내용량·성분·상호 possible, US-013 확인 필요(문구 여러 개 한 건으로) |
| us3_korean_only | 한글만 있는 라벨 | US-007 영어 표기 안내. 영문 필수항목 판정이 줄줄이 possible로 쏟아지지 않게(요약에서 영어 라벨 아님을 먼저 보여 주고 나머지는 보류) — 현재 동작을 먼저 기록하고 개선안을 보고 |
| us4_image_only | us1을 이미지로 만든 PDF(글자 레이어 없음) | 읽을 수 없음 안내(`readable:false`). 한국 모드에서도 같은 안내 |
실제 결과가 기대와 다르면 코드 수정 전에 `497-notes.md`에 원인(코드/규칙/기대값 오류)을 먼저 분류.

## 2. 이미지 PDF 안내 개선 (OCR은 아직 붙이지 않음)
- 읽을 수 없을 때 안내 문구 한글: "글자가 이미지로 들어 있어 읽지 못했습니다. 디자인 프로그램에서 글자를 살린 채(윤곽선 만들기 해제) PDF로 다시 내보내 주세요." 한 줄과 해결 방법 2개 이내. 새 카피는 이 안내에 한정.
- 일부 쪽만 텍스트 없음(혼합)인 경우도 쪽 번호로 안내.
- 향후 OCR 연결을 위해 `extract-pdf.ts`에 `extractFallback` 인터페이스(미구현, 항상 null)만 추가하고 호출 위치를 notes에 기록.

## 3. 미국 오탐 점검 (코드 로직만)
- us1에서 "Fragrance, Linalool, Limonene"이 알레르기 규칙(US-012)으로 잘못 확정되지 않는지, `Aqua` 같은 성분이 identity 단어로 오탐되지 않는지 확인.
- "Cures"·"treat"·"heal" 등은 단어 경계 일치(`Treatment` 같은 파생어 오탐 여부 기록), 정상 라벨의 "cream", "gel"이 의약품 주장으로 잡히지 않는지 확인.
- 한 글자·짧은 영문 패턴(`g`, `oz`, `ml`) 단독 매칭은 숫자 동반 시에만 인정(494 유사). 위반 시 로직 수정.
