## 4. 부품 표 (V5 켜짐에서만, 24 변형)
계열·변형·입력 요건·선호 아키타입·말뭉치 선택 여부 전체 표는 `docs/v5-overview.md` §"새 변형 24개".
- 말뭉치 ×8종에서 실제 선택됨: **19/24**. 선택되지 않음 5개: `benefits.rows2`·`benefits.iconlist`(입력 요건), `story.chapter`·`story.letter`(앞 1/3에서 더 큰 변형이 먼저 뽑힘), `spec.big3`(짧은 값 입력이 말뭉치에 없음). 이 5개는 **극단 입력 단위 렌더로만** 검증했다(8종 × 전 변형).
- 모든 문구는 입력 원문 + 순번 + 닫힌 영문 표지. 새 카피·수치·폰트·외부 주소 없음(회귀가 검사, 변이 테스트로 탐지력 확인).
