## 1. 배경
기획 담당이 식약처 원문 3건(화장품 표시·광고 관리 지침 2025.8.14., 사용할 때의 주의사항 고시 별표1, 시행규칙 별표4 2025.2.7.)을 받아 대조해 새 데이터를 만들었다. 모두 레포 `review/data/`에 있다:
1. `ad-phrases-kr_draft_v0.2.json` — 식약처 지침 별표1·2 기준 22개 항목(금지/기능성 한정/실증 필요). 기존 `ad-phrases-kr_draft_v0.1.json`(협회 해설서)을 **대체**한다. v0.1 파일은 삭제하지 말고 남기되 코드는 v0.2를 읽는다.
2. `kr-cautions_draft_v0.1.json` — 주의사항 고시 별표1의 성분별 15항(`ingredient_cautions`), 유형별 9항(`type_cautions`).
3. `kr-label-addenda_draft_v0.1.json` — 별표4 원문과 대조한 보강 11항(`KR-ADD-xxx`).

## 2. 항목
A. **광고 v0.2 연결**: 493차 로더를 v0.2 스키마(`kind`, `law_basis`, `regex_patterns`, `exception_note`, `fix_ko`, `fix_kind`)에 맞게 교체. 
   - `regex_patterns`는 대소문자 무시 정규식으로 지원. ReDoS 방지를 위해 입력 길이 상한과 패턴 단순성을 notes에 기록.
   - `condition: non_functional`은 기능성 체크 시 생략 또는 "심사·보고 범위 내인지 확인" 안내로 낮춤(선택해 기록).
   - `exception_note`가 있으면 접힘 영역에 "예외: …" 한 줄로 표시. 
   - 수정 제안은 항목의 `fix_ko`를 사용하고 기존 `fix-suggestions-kr` 중 같은 주제 id는 우선순위를 notes에 기록(중복 표시 금지).
   - `free`·`natural`·`SPF` 같은 영문 짧은 패턴은 497차 단어 경계 로직을 적용, 오탐 시험 추가(정상 라벨에서 `gluten free` 같은 파생, `Natural`이 성분명(`Natural Source` 등)인 경우는 전성분 영역 마스킹으로 제외되는지).
B. **주의사항 판정 신설**: 
   - 전성분에서 `ingredient_cautions[].trigger_ingredients_ko`를 찾고, 발견되면 주의사항 구간에 `match_keys_ko`가 모두 있는지 확인. 없으면 "확인 필요(해당 성분 주의사항 문구 누락 가능)" + `required_text_ko` 표시. `concentration_dependent: true`는 함량을 PDF로 알 수 없으므로 문구가 없을 때 "함량 조건에 해당하면 필요" 안내로 표시.
   - 주의사항 구간 식별: 기존 방식 재사용(`사용할 때의 주의사항` 제목 이후). 식별 실패 시 전체 텍스트에서 `match_keys` 존재 검색으로 폴백하고 notes에 한계 기록.
   - `type_cautions`는 사용자가 제품 유형을 고르는 입력이 있을 때만 판정. 이번 차수는 **입력 UI 추가: 유형 선택(복수) 접힘 영역 1개**(스크럽, 팩, 샴푸, 외음부세정제, 손발연화, 체취방지, 분무형 자외선차단, 에어로졸 해당 항목만). 새 카피는 라벨과 `condition_note` 표시에 한정. 선택 안 하면 type 판정 없음.
   - 벤조페논-3 항목은 `condition_note`의 시행일(2026-09-02)과 경과조치(2027-03-02)를 화면 항목에 한 줄 표시.
C. **별표4 보강 연결**: `kr-label-addenda`의 `check_type: code` 항목(ADD-001, 003, 004, 005, 006, 007, 008)을 기존 KR-LBL 규칙과 **중복 없이** 통합. 이미 같은 판정이 있으면 새 항목을 만들지 말고 기존 항목의 설명·수정 제안만 보강하고 그 내역을 표로 보고. `manual` 항목은 확인 질문 카드. ADD-004는 비누 제품 입력 체크가 없으므로 이번 차수는 문구 존재 시 통과/ "비누 제품이면" 안내 정도로 낮추고 notes에 기록.
D. **검증 스크립트 확장**: `validate-label-rules`에 새 3개 파일 포함(id 중복, 필수 필드, `trigger_ingredients_ko`가 비어 있지 않은지(ingredient_cautions), 정규식 컴파일 가능 여부).

## 3. 시험 (`label-check-504.ts`)
- 합성 입력: 살리실릭애씨드가 전성분에 있고 3세 이하 문구 없음 → 확인 필요. 문구 있음 → 통과. 알부틴만 있고 문구 없음 → 함량 안내. 카민 성분 + 문구 없음 → 확인 필요. 
- 광고: 무스테로이드(금지, MFDS-011)와 무첨가(실증, MFDS-E03)가 서로 다른 항목으로 잡히는지. `피부나이 -3살` 정규식. `30% 개선` 정규식. 정상 라벨(i1, i5, sample C, us1)에서 광고·주의사항 지적 0 또는 합리적 최소.
- 기존 시안 A·B·C 결과 전/후 표(새로 생기는 확인 필요 항목 목록).
- 기존 회귀 전부 유지.
