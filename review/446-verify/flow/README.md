# 후킹 흐름·밀도 (446차 4)

그림: `before.png` / `after.png` (왼쪽 = 페이지 끝 평문 블록, 오른쪽 = "한눈에 보기" 줄, 뷰티 합성 픽스처).

1. **"한눈에 보기" 아이콘 반복** — 키워드 근거가 없어 체크로 떨어지는 칩은 **번호 배지**(칸 순서 숫자, 듀오톤 원)로(`glanceIconSvg(..., index)`, 라이브·export 공용). 근거가 있는 칩(용량·배송 등)은 기존 아이콘. 말뭉치에서 한 줄 안 체크 아이콘 ≤1(전엔 2~3개). 새 문구 없음(숫자만).
2. **페이지 끝 긴 평문**(export 검색용 요약 블록) — 문구 불변. 180자 초과 문단은 문장 끝마다 줄바꿈, 제목은 12px 라벨형(자간 .14em), 문단은 좌측 선, 목록은 머리선 구분 행, 폭 576px 중앙. R4(긴 글) 위반은 이 블록이 린트 제외 대상이라 전·후 0/0(린트가 못 보던 구역).
3. **750px 같은 면 간격** — 넓은 폭 세로 여백 클래스를 3단으로 스냅(py-18·20·22·24 → 16, pt-10·11 → 12, pt-9 → 8, pt-14 → 16, pb-14 → 16; 라이브 클래스와 export 변수가 같은 원천). 이전 섹션 위 여백 규칙은 좁은·넓은 폭 값을 모두 보고 더 작은 쪽으로. 옅은 색 면 키를 하나("tint")로 합쳐 색 예산으로 같아진 면을 같은 면으로 판정.

| 지표(느슨한 스캔: 색 거리 ≤ 6인 이웃, 합성 21종) | 전(`580976c`) | 후 |

## 5. 쌍둥이 잔여 (446차 5)
- **사진 위 STEP 칩**: 라이브·export 모두 10px(좁은 폭 행 모드)·11px(넓은 폭)로 라벨 하한(12px) 미달이었고 v4 글자 하한 CSS가 클래스 글자를 못 올렸다(계산값 10px 확인). v4에서 12px·자간 label 토큰(`stepChipV4()`, 라이브·export 공용). 칩 면 위 글자 대비는 446차 1의 `v4SafeTheme`가 보장(색상환 전수 R7 0).
- **입력**: 말뭉치에 사진 위 칩이 나오는 step_card가 없어(패션은 착용컷이라 칩이 사진 밖) `scripts/gen-fixture-steps.ts`로 `tier-rich-tech-6p`에 기존 `compare-fashion` step_card를 그대로 복사해 넣음(새 문구 없음, 사진 번호만). 전체 페이지 표시 규칙에서는 usage_steps와 겹쳐 빠지므로 대조·회귀는 섹션 단독 렌더로 한다.
- **v3 폰트 쌍 자간**: 라이브는 `.font-mono{letter-spacing: 쌍 자간}`이 STEP 라벨에 걸리고(0.04em) export는 인라인 .32em이었다(3.5px ↔ 0.4px). v4에서 `.pagzly-step-tag`에 같은 쌍 자간 규칙을 `fontPairCss`에 추가(라이브는 해당 클래스가 없어 영향 없음). `live-audit.ts` 재대조: STEP 라벨 자간 차이 사라짐, 섹션 높이 620/619 동일.
