# 후킹 흐름·밀도 (446차 4)

그림: `before.png` / `after.png` (왼쪽 = 페이지 끝 평문 블록, 오른쪽 = "한눈에 보기" 줄, 뷰티 합성 픽스처).

1. **"한눈에 보기" 아이콘 반복** — 키워드 근거가 없어 체크로 떨어지는 칩은 **번호 배지**(칸 순서 숫자, 듀오톤 원)로(`glanceIconSvg(..., index)`, 라이브·export 공용). 근거가 있는 칩(용량·배송 등)은 기존 아이콘. 말뭉치에서 한 줄 안 체크 아이콘 ≤1(전엔 2~3개). 새 문구 없음(숫자만).
2. **페이지 끝 긴 평문**(export 검색용 요약 블록) — 문구 불변. 180자 초과 문단은 문장 끝마다 줄바꿈, 제목은 12px 라벨형(자간 .14em), 문단은 좌측 선, 목록은 머리선 구분 행, 폭 576px 중앙. R4(긴 글) 위반은 이 블록이 린트 제외 대상이라 전·후 0/0(린트가 못 보던 구역).
3. **750px 같은 면 간격** — 넓은 폭 세로 여백 클래스를 3단으로 스냅(py-18·20·22·24 → 16, pt-10·11 → 12, pt-9 → 8, pt-14 → 16, pb-14 → 16; 라이브 클래스와 export 변수가 같은 원천). 이전 섹션 위 여백 규칙은 좁은·넓은 폭 값을 모두 보고 더 작은 쪽으로. 옅은 색 면 키를 하나("tint")로 합쳐 색 예산으로 같아진 면을 같은 면으로 판정.

| 지표(느슨한 스캔: 색 거리 ≤ 6인 이웃, 합성 21종) | 전(`580976c`) | 후 |
|---|---|---|
| 같은 면 이웃 쌍 | 71 | 79(색 예산으로 면이 더 비슷해짐) |
| 390px 간격 96 초과 | 3 | 4 |
| 750px 간격 96 초과 | 10 | 8 |
| 750px 최대 간격 | 144 | 112 |
| 저장소 지표 gapBig·gapUneven·3단 밖·급변 | 0·0·0·0 | 0·0·0·0 |

남은 96 초과는 모두 앞 64 + 뒤 48=112 꼴이고, 뒤 블록이 모티프 안전 영역(위 여백 > 40 필요) 때문에 줄이지 못하는 v4 블록이거나 임팩트↔임팩트다(규칙 설계상 한계). 390px 쪽 +1은 색 예산으로 비교 가능한 쌍이 늘어난 영향.
