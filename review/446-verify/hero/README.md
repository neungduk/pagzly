- **고스트 글자 폭 맞춤**(`lib/hero-spec.ts ghostFitPx`, v4): 글자별 폭(em) 어림 → 좁은 화면 폭 390의 84%(좌우 안전 여백 8%) 안으로 크기를 줄이고, 44px 아래면 고스트를 끈다. 한글 9자 이상은 대부분 꺼진다(전엔 76px로 약 650px 폭이라 사진 가장자리에서 잘림). 라이브·export가 같은 마크업 함수를 쓴다. D형은 오른쪽 `-6px` 돌출을 `8%` 안쪽으로.
