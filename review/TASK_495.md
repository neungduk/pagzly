# 495차 — 회원·검수 신청 흐름 프론트(MVP) 

## 0. 규칙
- 유료 호출·Production·main 금지. 코드 삭제 금지. 상세페이지·기존 결제(Toss)·크레딧 코드 변경 금지(숨김 상태 유지). "위반" 단정·"완벽/보장" 표현 금지.
- `review/495-targets.md`에 코드 전 기재. Read 후 Write/Edit. 마무리 전 `npx tsc --noEmit`, `npm run build`. 커밋 최대 4개. 보고서 `review/495cha-report.md`.
- DB 변경은 **마이그레이션 SQL 파일 작성까지만**(`supabase/migrations/`), 적용은 기획 담당·사용자가 한다. 서비스키·실키 사용·출력 금지.

## 1. 결정된 기본값 (사용자 승인 전 임시 — 바꾸기 쉽게 상수로)
- 기존 Supabase 로그인(가입/로그인/비번찾기)을 그대로 재사용한다.
- **비회원**: 점검 1회 미리보기(현재 `/label-check` 동작 유지, 저장 없음, IP 제한 유지).
- **회원**: 로그인 후 `/label-check/new`에서 "검수 신청" → 업로드 → 결과 → 내 결과 목록.
- **업로드 파일은 서버에 저장하지 않는다**(현행 유지). 저장하는 것은 **결과 요약 텍스트(항목 제목·상태)와 메타데이터**뿐이며, 원문 PDF 텍스트·파일명 외 개인정보는 저장 금지. 파일명은 저장하지 않고 사용자가 붙이는 "제품명(선택)"만 저장.
- 결제는 이번 차수 **제외**(무료 베타). 결제 자리는 "곧 제공" 문구 없이 아예 노출하지 않는다.

## 2. 화면(앱 라우트)
1. `/label-check` — 현행 소개+샘플+즉시 점검 유지. 상단에 로그인/내 결과 링크 추가. 새 카피는 최소.
2. `/label-check/new` — 로그인 필요(미로그인 시 `/login?next=` 복귀). 단계: ① 시장 선택(한국/미국) ② 옵션(씻어내는 제품, 기능성, 수입품, 전문가용 등 기존 체크박스) ③ 제품명(선택) ④ PDF 업로드 ⑤ 진행 표시 ⑥ 결과 + 수정 제안 모아 보기. 결과 화면은 기존 컴포넌트 재사용.
3. `/label-check/history` — 내 결과 목록(날짜·제품명·시장·요약 4수치). 항목 클릭 시 **저장된 요약만** 표시(PDF 재분석 불가 안내 한 줄). 삭제 버튼(본인 행만, 확인 단계 포함).
4. 모바일 390/320 폭에서 가로 스크롤 없음. 접근성: 업로드 영역 키보드 사용, 오류 메시지 role="alert".
5. 오류·빈 상태: 로그인 만료, 용량 초과, PDF 아님, 읽을 수 없음(스캔), 요청 제한, 서버 오류 각각 한글 문구.

## 3. 서버
- 테이블 `label_check_runs` 마이그레이션 SQL: id, user_id(auth.users), market, product_name(nullable, 80자), options(jsonb), summary(jsonb: possible/attention/unknown/pass/manual), findings(jsonb: 항목 제목·상태·한 줄 설명만), created_at. **RLS: 본인 행만 select/insert/delete**, update 없음. 한 사용자 최근 200건 초과 시 오래된 것부터 삭제하는 로직 또는 insert 제한 중 하나를 notes에 선택 기록.
- `POST /api/label-check`는 로그인 사용자일 때만 결과 요약을 저장(옵션 `save=true`). 저장 실패가 점검 결과 응답을 막지 않게 한다. 저장 내용에 업로드 원문·PDF 텍스트 일절 포함 금지(단위 시험으로 검증).
- 회원 레이트 리밋은 비회원보다 완화하되 상수로.
- 약관·개인정보 페이지에 "점검 결과 요약 저장·삭제 방법" 문장 추가는 **하지 말고** 필요 문구 초안만 `review/495-notes.md`에(법률 검토 대상).

## 4. 시험
- 미로그인 `/label-check/new` 접근 → 로그인으로 이동.
- 저장 payload 검사 스크립트: findings에 PDF 원문 포함 안 됨.
- 타 사용자 행 접근 불가는 SQL 정책 검토로 notes에 기재(실DB 시험 불가 명시).
- 회귀 483/493/494 유지.
