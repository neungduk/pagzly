- 표시 전용 섹션마다 **입력(섹션 데이터 + 토큰) → HTML 문자열을 만드는 순수 함수**를 만들고, 라이브(`DetailSectionRenderer`)는 그 결과를 쓰고(React 노드로 파싱하거나 동일 구조 컴포넌트가 같은 클래스·인라인 스타일을 방출) export도 같은 함수를 호출. **임팩트 블록이 이미 쓰는 공용 방식**(예: `impactHtml`)을 그대로 따른다.
- 대상 후보(인벤토리 확정): 강조 카드, 페르소나(고민/대상), 체크리스트 이전 분기, FAQ, 표(스펙/사이즈/배송), 주의·고지, 구매 카드, 후기/신뢰 블록.
- 섹션마다 **전환 순서**: ① 공용 빌더가 off 상태에서 기존 렌더 **문자열과 동일**하도록 먼저 구현(리팩터링, 동작 불변) → 문자열 diff 0 확인 → ② v4 on에서만 새 디자인 언어(제목 프리셋, 깊이·여백·행간 토큰) 적용.
