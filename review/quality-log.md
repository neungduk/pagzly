# 상세페이지 품질 로그 (레퍼런스 연습)

기준: `review/reference-patterns.md` §8–9  
방식: 이미지 재생성 없음, QA API 생략, 코드 리뷰만  
목표: 슬롯/3색/히어로-only는 유지한 채 리듬·여백·타이포·톤만 접근

채점: 섹션 리듬 / 여백 / 타이포 / 톤, 각 5점. 평균 4.5 또는 3회 연속 무변화 시 종료.

---

## Cycle 1 — 기준선 (탭 UI 적용 직후, 레이아웃 미변경)

기존 풀폭 블록 + POINT 스택 + 갤러리 `gap-px` + 히어로 85svh.

| 항목 | 점수 | 메모 |
|------|------|------|
| 리듬 | 4.0 | 한 섹션 한 메시지. 사용법이 POINT 뒤에 있어 레퍼런스 설득 흐름과 슬롯 순서가 어긋나 보임. 슬롯은 안 바꿈. |
| 여백 | 4.0 | 내부 py 48/80은 맞음. 갤러리 제목–사진 간격이 조금 어정쩡. |
| 타이포 | 3.5 | 히어로 5xl은 좋음. POINT 라벨이 본문과 같은 sans라 위계가 약함. |
| 톤 | 4.0 | 3색·히어로 장식만. 본문은 기능적. |

평균 **3.9**. 다음: POINT/카테고리 라벨을 mono+트래킹으로.
