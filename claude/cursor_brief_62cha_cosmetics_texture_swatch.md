# 62차 — 화장품 텍스처 스와치 컷 (기준 3 마지막 보완, 57차 이후 착수)

생성: 2026-09-01

## 배경

채점 결과 기준 3(카테고리 관습적 시그니처 컷)은 4/5 카테고리 합격이고
**화장품만 부분 합격**입니다. 51차 화장품 스크린샷을 다시 보면 어두운 스튜디오
무드컷(드로퍼+화장솜)은 있지만, 베르가모 레퍼런스의 "크림/액체를 짜서 펼쳐놓은
텍스처 스와치" — 화장품 카테고리에서 소비자가 관습적으로 기대하는 컷 — 에
해당하는 이미지는 없습니다.

`lib/backdrop-prompt-templates.ts`의 화장품 `radiant`/`premium_dark` 템플릿은
배경 자체의 텍스처(꽃잎/파우더 힌트)를 다루는 것이지, 제품 내용물(세럼·크림
자체)의 텍스처 클로즈업이 아닙니다 — 이건 배경 템플릿과는 다른, 별도의 씬
카테고리입니다.

## 작업

화장품 카테고리에 한해 "텍스처 스와치" 씬을 새로 추가해주세요:

- 제형 정보(컨셉 브리프 또는 spec_table의 "제형" 값 — 세럼/크림/앰플/로션 등)를
  참고해서, 액체 또는 크림이 매끈한 표면(유리판, 세라믹 팔레트, 스와치 카드 등)
  위에 발려 있거나 짜여 있는 매크로 클로즈업 프롬프트를 추가해주세요.
  - 예: "제형이 소량 짜여져 매끈한 표면 위에 자연스럽게 펼쳐진 매크로샷,
    질감(윤기/점도)이 선명하게 보임, 얕은 심도, 부드러운 스튜디오 조명"
  - 제형 정보가 없거나 불명확하면(플레이스홀더 등) 이 씬을 생성하지 않고
    기존 방식(무드컷 등)으로 폴백 — 억지로 어울리지 않는 텍스처를 만들지
    않습니다.
- 배치 위치: 기존 `image_text` 섹션 중 `ingredient_highlight` 슬롯 등 이미
  성분/텍스처를 다루는 슬롯 하나에 우선 배정해주세요. 새 섹션 타입을 만들
  필요는 없고, 해당 슬롯의 이미지 소스를 이 새 씬 프롬프트로 생성하면 됩니다.
- 61차와 동일하게, 이 씬을 생성할 때도 상품 전체에서 이미 정해진 조명 락(있다면)
  을 따라가도록 해주세요 — 61차가 먼저 끝났다면 그 shadow 재사용 구조를
  그대로 활용, 아직이면 기존 방식대로 처리해도 무방합니다.

## 검증 (실제 생성 필요, 화장품 1개로 제한)

- 화장품 1개 상품, 실제 `mode: final` 생성 1회.
- 스크린샷으로 (a) 텍스처가 실제 제형처럼 자연스러운지 (합성 티 없이 질감이
  그럴듯한지), (b) 페이지에 이 컷이 최소 1장 존재하는지 육안 확인.

## 하지 않는 것

- 화장품 외 다른 카테고리 확장 안 함
- 기존 라이팅락/화이트밸런스/그림자 로직 변경 안 함
- `radiant`/`premium_dark` 등 기존 배경 템플릿 내용 변경 안 함 — 이건 신규
  씬 추가이지 기존 템플릿 수정이 아닙니다
- `backdrop-prompt-templates.ts`를 건드리니 57차 변경이 완전히 반영된 뒤에
  착수해주세요 (통합 지시서 참고)
