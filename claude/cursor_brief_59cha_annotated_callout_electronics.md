# 59차 — 주석형 콜아웃 (전자제품 부품/기능 라벨, 60차 이후 착수)

생성: 2026-09-01

## 배경

채점 결과 기준 4(주석형 콜아웃)는 5개 카테고리 전부 불합격입니다. 이어버드
레퍼런스는 제품 사진 위에 가는 선으로 특정 부위를 짚어서 "특허 기술", "커널형
이어팁" 같은 라벨을 붙이는데, 우리 결과물엔 이런 게 없습니다.

코드에서 확인: `ImageTextSection`엔 이미 `layout?: "full" | "compact" |
"callout"`이 있고 `"callout"`은 이렇게 정의돼 있습니다 (`lib/types/generate.ts`
139~142행):

```ts
/** 기본 "full" = 기존 풀사이즈 이미지+텍스트. "compact" = 작은 썸네일+텍스트 한 줄. "callout" = 사진 위 말풍선 강조 */
layout?: "full" | "compact" | "callout";
/** layout:"callout"일 때 사진 위 말풍선에 표시할 짧은 강조 문구 (12~18자 권장) */
callout?: string;
```

`DetailSectionRenderer.tsx`에서 실제로 이건 사진 하단 중앙에 말풍선 하나
("시끄러운 세상, 이제 괜찮아" 같은) 붙이는 무드 강조용입니다. `pointLabel`
("POINT 01" 배지, 1247~1250행)도 사진 코너에 붙는 라벨일 뿐 특정 부위를 짚지
않습니다. 즉 "말풍선형 콜아웃"은 있지만 "주석형(부위를 짚는) 콜아웃"은 없는
상태 — 기준 4가 요구하는 건 후자입니다.

## 이번 라운드 범위

**전자제품 카테고리 1개에만 한정**합니다. 부품/기능이 많은 카테고리부터
검증하고, 결과가 좋으면 다음 라운드에서 다른 카테고리로 확장합니다.

## 작업 A — 새 레이아웃 `"annotated"` + 타입 추가

`ImageTextSection`에 다음을 추가해주세요:

```ts
layout?: "full" | "compact" | "callout" | "annotated";
/** layout:"annotated"일 때, 사진 위에 리더라인으로 짚을 포인트들 (최대 3~4개 권장) */
annotations?: { label: string; xPct: number; yPct: number }[];
```

`xPct`/`yPct`는 이미지 좌상단 기준 0~100 퍼센트 좌표입니다.

`DetailSectionRenderer.tsx`에 `isAnnotated = section.layout === "annotated"`
분기를 추가하고, 각 `annotations` 항목마다: (1) 사진 위 해당 좌표에 작은 원형
점(dot), (2) 점에서 사진 바깥 여백까지 이어지는 가는 리더라인(SVG `<line>` 또는
CSS로 회전된 `<div>` 선), (3) 라인 끝에 라벨 텍스트 칩을 렌더링해주세요. 스타일은
55차 `lib/fashion-size-diagram.ts`의 SVG 화살표 렌더링(가는 선 + 작은 원)과
톤을 맞춰주시면 페이지 전체 비주얼 언어가 일관됩니다. `annotations`가 비어있거나
없으면 이 레이아웃은 렌더링하지 않습니다(=일반 `full`로 폴백하거나 섹션 생략).

## 작업 B — 좌표는 누가 정하나 (Vision 활용, 실패 시 안전하게 생략)

부품 위치 좌표는 텍스트 생성 AI가 알 수 없는 정보입니다. 우리 파이프라인이
이미 Claude Vision으로 업로드 사진을 분석하는 단계가 있으니(그림자 방향 분석
`analyzeShadowDirection` 등), **전자제품 카테고리 한정으로** 같은 이미지 분석
호출에 "사진에서 이 기능/부품이 시각적으로 위치한 대략적 좌표(0~100%, 근사치
허용)"를 함께 요청하는 방식을 우선 검토해주세요. 기존 Vision 호출에 얹을 수
있으면 추가 API 호출 비용 없이 가능합니다.

Vision이 좌표를 신뢰성 있게 못 주는 경우(엉뚱한 위치를 짚는 등)에는 **무리하게
근사 좌표를 쓰지 말고 이 레이아웃 자체를 생성하지 않는 쪽으로 안전하게
처리**해주세요 — 부정확한 위치에 라벨을 찍는 게 없는 것보다 나쁩니다.
