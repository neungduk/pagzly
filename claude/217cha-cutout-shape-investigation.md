## 결론

**가설이 사실로 확인됐습니다.** 214/215/216차에서 반복 사용된 electronics 상품컷
(`scripts/test-assets/전자제품/02-pexels-33936400.jpeg`)은 케이스 1개 + 낱개
이어버드 2개, 총 **3개의 분리된 오브젝트가 검은 배경 위에 흩어져 있는 "플랫레이"
사진**입니다. 손으로 쥔 물체 사진이 아니라 제품 소개용 아트 컷입니다.

`removeProductBackground()`(Replicate 배경 제거)는 이미지 전체에 대해 배경만
제거하므로, 이 3개 오브젝트가 **각각 분리된 컷아웃이 아니라 투명한 공백을 포함한
하나의 큰 컷아웃**으로 나옵니다. 216차 합성 결과 이미지(`electronics-composite.png`)를
다시 확인해보면 실제로 **케이스와 낱개 이어버드 하나가 모두 그대로 붙어 있음**을
육안으로 재확인했습니다 — 이는 코드를 추측한 게 아니라 실제 산출물로 직접 검증한
사실입니다. 손이 쥘 수 있는 하나의 형태가 아니라 "제품 사진 조각"을 통째로 손 위에
붙인 셈이라, 접촉 그림자가 안 생기고 색/질감이 이질적으로 보였던 것이 상당 부분
설명됩니다.

## 근거

1. **상품 이미지 직접 열람**: `02-pexels-33936400.jpeg` — 케이스(중앙) + 이어버드
   2개(우상단, 좌하단)가 각각 다른 각도로 떠 있는 구도. 파랑/주황 대각선 스튜디오
   조명. 단일 오브젝트가 아님.
2. **파이프라인 코드 확인** (`lib/lifestyle-product-composite.ts` 927~943행):
   `removeProductBackground(productImageUrl)` → 이미지 전체 배경 제거 →
   `defringeCutoutEdges()`로 가장자리 번짐만 제거 → 이 컷아웃 버퍼 전체가 그대로
   `detectHandPlacementWithGraspRetry()`와 `pasteCutoutOnScene()`에 전달됨. 오브젝트
   분리·개별 선택 로직은 없음 — 즉 원본 상품 사진에 오브젝트가 여러 개면 컷아웃도
   여러 개가 통째로 붙어 나오는 구조.
3. **216차 산출물 재확인**: `electronics-composite.png`를 다시 열람 — 케이스와 낱개
   이어버드가 원본 상품 사진 속 배치 그대로 붙어 있어, 위 가설과 정확히 일치.
