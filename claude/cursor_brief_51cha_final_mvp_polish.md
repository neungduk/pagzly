# 51차 — "사람들에게 보여줄 수준" 최종 마무리 (실제 쇼핑몰 5개 카테고리 재조사)

생성: 2026-09-01

## 배경

이제 정말 마지막 단계입니다. 50차(더보기 접기·판매자 신뢰 배너·3단 카피·패션 미니멀
배경)에 이어서, 이번엔 화장품·패션뿐 아니라 **전자제품·식품·반려동물까지 5개 카테고리
전체**를 실제 쇼핑몰(올리브영, 무신사, 29CM, 마켓컬리)에서 직접 둘러보고 우리 결과물과
비교했습니다. 목표는 "MVP여도 사람들이 우와 하고 실제로 쓸 수 있는 수준"을 지금 확실히
만드는 것입니다.

**이번엔 최종 검증 단계에서 실제 생성 테스트를 허용합니다.** 지금까지는 비용 때문에
코드 검증만 했지만, 아래 Tier 1(코드/템플릿) 작업을 모두 끝낸 뒤 **카테고리 5개(화장품/
패션/식품/전자제품/반려동물) 각 1회씩만** 실제로 생성해서 눈으로 확인하는 걸 이번 라운드
완료 조건에 포함합니다. 여러 번 돌리지 말고 카테고리당 딱 1번, 총 5회로 제한하세요.

## 조사 발견 (5개 카테고리, 실제 상품 페이지 직접 확인)

### 발견 1 — 브랜드 협업/타이틀 카드로 상세설명이 시작된다

29CM 에어프라이어(제니퍼룸 X 위글위글) 상세설명 첫 화면은 상품 소개가 아니라, 단색
배경 위에 **브랜드 로고 두 개를 나란히 배치 + 초대형 영문 카테고리명("AIR FRYER")**
타이틀 카드입니다. 우리는 브랜드명이 있어도 히어로에 작게 표시될 뿐, 이런 "브랜드
임팩트 오프너"가 없습니다.

### 발견 2 — "POINT.1/POINT.2" 넘버링 + 초대형 키워드 타이포 대비

기능 강조 섹션마다 작은 알약형 배지("POINT.1") + 초대형 압축 영문 키워드("COMPACT") +
한글 설명 1~2줄 조합을 씁니다. 우리 checklist/highlight_box는 타이포 크기 대비가
상대적으로 밋밋해서 이런 "훅"이 약합니다.

### 발견 3 — 브랜드 패턴/일러스트 텍스처가 배경에 은은하게 깔린다

위글위글 데이지 패턴, 마켓컬리 채소 일러스트 아이콘처럼, 순수 그라데이션이 아니라
브랜드/카테고리에 맞는 **반복 패턴이나 일러스트 모티프**가 배경 장식으로 쓰입니다. 우리는
순수 단색·그라데이션만 쓰고 패턴 텍스처가 전혀 없어서 상대적으로 "밋밋한 템플릿"처럼
보입니다.

### 발견 4 — 식품 카테고리는 "완성된 요리" 무드샷이 핵심이다

마켓컬리 우동 상세페이지는 스튜디오 제품컷보다 **김이 나는 완성 요리를 그릇에 담아 찍은
무드샷**이 상단 가까이에 옵니다. 우리 AI 배경 합성은 스튜디오풍 배경 위주라, 식품
카테고리에서 특히 "먹음직스러움"이 약할 가능성이 있습니다.

### 발견 5 — "정확히 뭐가 바뀌었는지" 투명 공개형 카피

반려동물 간식(바잇미) 상세페이지의 "RENEWAL!" 배너는 "사과 대신 고구마로 변경", "USDA
승인 시설"처럼 **구체적으로 뭐가 어떻게 바뀌었는지**를 체크마크(✅)와 함께 공개합니다.
우리 checklist는 일반적인 효능 나열 위주라 이런 "투명 공개형" 신뢰 카피가 약합니다.

### 발견 6 — 인증·보증 마크는 별도 강조색으로 하이라이트된다

"USDA 승인" 같은 인증 문구가 본문과 다른 강조색(초록)으로 처리돼 눈에 띕니다. 우리는
`certifications` 입력값이 있어도 다른 본문과 같은 톤으로 나열될 가능성이 큽니다.

## 이번 라운드 작업 — Tier 1 (코드/템플릿, API 비용 없음, 먼저 진행)

### T1-A. 브랜드 타이틀 카드 섹션

`brandName`이 입력된 경우에 한해, 히어로 직후(또는 `brand_story` 섹션 스타일 강화)에
**단색 배경 + 브랜드명 + 카테고리 영문/한글 키워드**를 큼직하게 보여주는 타이틀 카드
스타일을 추가하세요. 새 섹션 타입을 만들 필요 없이 기존 `brand_story`의 렌더링 스타일을
"카드형 타이틀"로 보강하는 정도로 충분합니다. `brandName`이 없으면 지금처럼 이 섹션 자체를
생략합니다(기존 규칙 유지).

### T1-B. 넘버링 배지 + 초대형 키워드 타이포 옵션

`highlight_box` 또는 `checklist`의 헤딩 렌더링에 "작은 배지(순번) + 초대형 압축 폰트
키워드" 스타일 변형을 하나 추가하세요. 지금 있는 타이포 토큰(`TYPO` 관련 상수)에 새
크기/폰트-웨이트 조합을 추가하는 정도면 됩니다. 3색 규칙·슬롯 구조는 그대로 유지하고,
타이포 크기/굵기만 조정하는 겁니다.

### T1-C. 배경 패턴 텍스처 (SVG, AI 이미지 생성 아님)

`design-tokens.ts`에 카테고리별로 아주 은은한(투명도 3~6% 수준) SVG 반복 패턴을
배경에 오버레이할 수 있는 옵션을 추가하세요 (예: 화장품은 물방울/기포 모티프, 식품은
곡선형 잎사귀 모티프, 반려동물은 발바닥 모티프 — 전부 CSS `background-image` + inline
SVG data URI로, AI 이미지 생성 API 호출이 전혀 필요 없습니다). **기본은 끄고, 카테고리별로
옵트인**하는 방식으로 도입해서 기존 페이지 회귀 위험을 최소화하세요.

### T1-D. 식품 카테고리 배경 합성 프롬프트 — "무드샷" 방향 보강

`lib/backdrop-prompt-templates.ts`(또는 관련 프롬프트 파일)에서 식품/건강기능식품
카테고리에 한해, 배경 합성 지시문에 "완성된 요리·따뜻한 질감·자연광 무드" 같은 방향을
한두 문장 추가하세요. 기존 프롬프트 구조·다른 카테고리는 건드리지 마세요.

### T1-E. "무엇이 바뀌었는지" 투명 공개형 카피 유도

`app/api/generate/route.ts`의 checklist 프롬프트 지시문에, 판매자가 입력한
`keyFeatures`/`ingredients`에 "개선/변경/기존 대비" 같은 뉘앙스가 있으면 ✅ 체크마크
스타일로 "무엇이 어떻게 바뀌었는지"를 구체적으로 표현하도록 안내를 추가하세요. 근거 없으면
당연히 생략(기존 원칙 동일).

### T1-F. 인증 마크 강조 스타일

`certifications` 필드가 채워진 경우, 해당 텍스트를 렌더링할 때 본문과 다른 accent 강조색
(밑줄 또는 배경 하이라이트)으로 처리하세요. 이미 `certifications` 표시 로직이 있는
곳(spec_table, brand_story 등)에서 스타일만 추가하면 됩니다.

## 이번 라운드 작업 — Tier 2 (최종 실제 검증, 카테고리당 1회만)

Tier 1을 전부 구현하고 `tsc` 통과까지 마친 뒤, **화장품/패션/식품/전자제품/반려동물 각

7장 이상 조건은 기존 QA 테스트와 동일합니다. 각 카테고리 결과 풀페이지 스크린샷을

실제 화면에 눈으로 보이는지, 그리고 49차·50차에서 고친 색상·배경이 여전히 잘 나오는지
같이 확인하세요.
