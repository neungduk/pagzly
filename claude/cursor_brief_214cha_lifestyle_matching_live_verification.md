# 214차 — 라이프스타일 합성 매칭 3축 실사 검증 (유료, 정확히 2건만)

생성: 2026-09-17 · **사용자가 이 라운드에 한해 명시적으로 유료 생성을 허가했습니다 — "2건만 하자".**

## 절대 원칙 — 이번엔 다릅니다, 반드시 지킬 것

**정확히 2건의 실제(`mode: final`, `TEST_MODE=false`) 생성만 실행하세요. 3건째부터는 사용자
재허가 없이 절대 실행 금지입니다.** 재시도·QA 재실행도 이 2건 카운트에 포함됩니다 — 실패해도
무한 재시도하지 말고, 1회 실패 시 원인을 보고서에 남기고 멈춘 뒤 지시를 기다리세요. 이 원칙은
프로젝트 전체의 표준 하드 가드레일("사용자 허가 없이 생성 API 호출 금지")의 **일회성 예외**이며,
이번 브리프가 끝나면 다시 원래대로 "허가 없이는 0건"으로 돌아갑니다.

## 배경

211차에서 `pasteCutoutOnScene()`(라이프스타일 픽셀 페이스트, `lib/lifestyle-product-composite.ts`)에
컷아웃-배경 매칭 3축(화이트밸런스·선명도·그레인)을 추가했고, 순수 함수 단위 테스트(`scripts/
211cha-lifestyle-matching-verify.ts`)는 전부 통과했습니다. 하지만 **실제 생성물에서 육안으로
자연스러워 보이는지는 아직 확인 못 했습니다** — 211차 완료 보고서가 "212차 후보"로 남겨뒀던 항목이고,
이번에 사용자가 직접 유료 API 허가를 주셨습니다.

## 할 것

1. **카테고리가 다른 2건**을 준비하세요(예: 화장품/뷰티 1건 + 전자제품 1건, 또는 다른 조합도 무방) —
   서로 다른 배경 색감·질감에서 매칭이 어떻게 작동하는지 보기 위함입니다.
2. **각 건에 반드시 "인물/라이프스타일 사진"(`lifestyleImageUrl`)을 업로드**하세요 — 이게 있어야
   `pasteCutoutOnScene()` 경로(211차가 수정한 그 경로)가 실제로 돌아갑니다. AI가 인물을 새로
   생성하는 옵션(`img2img`, `generate-lifestyle-shots.ts` 경로)은 **끄세요** — 이번 검증은
   "실제 라이프스타일 사진 + 실제 상품 컷아웃" 픽셀 페이스트 경로만 대상입니다.
3. 기존 테스트 자산을 재사용하세요 — 새로 사진을 구하거나 만들 필요 없습니다:
   - 상품 사진: `scripts/test-assets/화장품-뷰티/`, `scripts/test-assets/전자제품/` 등 카테고리별
     폴더에 이미 있는 사진 사용.
   - 라이프스타일 배경 사진: `scripts/test-assets/_66cha-lifestyle-e2e/`
     (`scripts/66cha-lifestyle-e2e-qa.ts`가 이미 이 조합으로 유료 E2E를 돌린 전례가 있으니 그
     스크립트의 패턴을 참고/재사용해도 됩니다 — dev 서버(`localhost:3000`) + Playwright로 실제
     폼 제출까지 가는 방식이든, 파이프라인 함수를 직접 호출하는 방식이든 편한 쪽으로 하되 **실제
     API 호출이 나가는 `mode: final` 경로**여야 합니다).
4. 생성이 끝나면 **결과 상세페이지에서 라이프스타일 합성 섹션(사람이 상품을 들고 있는 컷)만** 스크린샷
   또는 이미지 파일로 캡처하세요 — 전체 페이지 스크린샷일 필요는 없고, 합성 품질을 볼 수 있는
   해당 이미지만 있으면 됩니다.
5. **실제 API 비용 로그를 그대로 보고서에 남기세요** — `photoCostBreakdown`, Replicate 호출 로그
   등 기존에 있는 비용 추적 로직 그대로 사용(새 로깅 코드 추가 불필요). 정확히 2건 실행됐다는 걸
   비용 로그로도 증명해주세요.

## 코드는 건드리지 않습니다

이번 라운드는 **코드 변경이 전혀 없습니다** — 순수하게 기존 파이프라인을 실행하고 결과를
관찰·보고하는 것만이 목적입니다. `lib/lifestyle-product-composite.ts`, `lib/photo-composite.ts`
등 어떤 파일도 수정하지 마세요.
