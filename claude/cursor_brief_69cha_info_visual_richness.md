# 69차 — INFO 섹션 주변 시각 요소 확장

생성: 2026-09-02

## 배경

사용자 요청: "인포부분에서 그림이나 이런것도 좀 더 잘 들어가고." 65차에서
라벨링된 원형 성분 크롭 페어(`layout: "circle-pair"`)를 추가했지만, 이건
**성분 필드에 정확히 2개 이상 값이 있을 때만** 발동하는 조건부 기능이라
실제로는 발동 안 하는 상품이 많을 수 있습니다. 이번 라운드는 이 발동률을
높이고, INFO(`spec_table`) 자체도 조금 더 시각적으로 보강합니다.

## 작업 A — 원형 크롭 발동 조건 완화 (성분 1개도 지원)

`lib/ingredient-labels.ts`의 `parseIngredientPairLabels()`는 지금 정확히
2개를 못 뽑으면 `null`을 반환해서 아예 컴포넌트가 안 생깁니다. 성분이 1개만
있어도 뭔가 보여줄 수 있게 완화해주세요:

- `lib/types/generate.ts`의 `ImageTextSection`에 `layout: "circle-solo"` 옵션과
  `circleSolo?: { imageUrl: string; label: string }` 필드를 추가.
- 성분이 정확히 1개만 파싱될 때는 `circle-solo`(원형 1개, 좀 더 크게), 2개
  이상일 때는 기존 `circle-pair`(2개 중 대표 2개 선택)를 쓰도록
  `applyIngredientCirclePair()`(또는 이름을 `applyIngredientCircleVisual()`로
  바꿔도 좋습니다)를 분기해주세요.
- 성분 필드가 아예 비어있거나 값이 없으면(기존과 동일) 여전히 아무것도
  생성하지 않습니다 — 이 부분은 그대로 유지, 지어내기 금지 원칙 불변.
- `DetailSectionRenderer.tsx`에 `circle-solo` 렌더 분기 추가 (기존
  `circle-pair` 스타일과 톤 맞추되, 원 1개를 조금 더 크게 — 예: 기존
  `h-24 w-24`/`sm:h-[7.5rem]` 대비 1.2~1.3배 정도).

## 작업 B — `spec_table`(INFO) 자체 이미지 보강

`DetailSectionRenderer.tsx`의 `spec_table` 렌더 분기(현재 `specThumb` 썸네일
1장 + 테이블 구조)를 확인해서, **`detail`/`lifestyle` 역할 이미지가 2장 이상
남아있을 때** 썸네일을 1장이 아니라 작은 이미지 2~3장을 가로로 배치하는
옵션을 추가해주세요:

- 이미지가 1장뿐이거나 여유 이미지가 없으면 기존처럼 1장 그대로(회귀 없음).
- 이미지 배정은 `assign-section-images.ts`의 기존 least-used 배정 로직을
  그대로 활용하되, `spec_table`에 배정 가능한 이미지 개수를 (지금 1장 고정으로
  보이는 부분을) 최대 3장까지 허용하도록 확장.
- 새 이미지들에 새로 AI 생성은 하지 않습니다 — 기존 업로드/보정된 이미지
  재사용만.

## 작업 C — `spec_table` 배경 색 액센트 (다채로움, 선택)

지금 `spec_table`은 흰 배경에 테이블만 있어서 밋밋합니다. 카테고리 테마의
`baseNeutral`(1차 채점에서 이미 확정된 통일감 있는 배색)을 아주 옅게 섹션
배경에 깔아서(예: 5~8% 정도의 옅은 틴트) 페이지의 다른 섹션들과 톤이
이어지도록 해주세요. 가독성(테이블 셀 대비)이 떨어지면 안 되니, 실제
스크린샷으로 텍스트 대비를 확인해주세요.

## 하지 않는 것

- 성분/소재 값이 없는데 라벨을 지어내는 것 (엄격 금지, 불변)
- 기존 `spec_table` 테이블 구조 자체 변경 (컬럼/행 로직은 그대로)
- 다른 섹션(`ingredient_highlight`, `texture_feel` 등) 로직 변경
