## 처리 순서 권장

1. **58차** (이미 별도 전달, 진행 중이면 그대로 계속)
2. **60차 → 59차** 순서 권장: 둘 다 `lib/types/generate.ts`의
   `ImageTextSection`과 `components/DetailSectionRenderer.tsx`의 `image_text`
   렌더 분기를 건드립니다. 60차가 필드 하나(`imageShape`) 추가라 더 작고
   간단하니 먼저 끝내고, 59차(`annotations` 필드 + 새 레이아웃)를 그 위에
   얹는 순서가 충돌이 적습니다. 두 브리프를 병렬로 다른 사람이 동시에 작업하는
   게 아니라면 순서만 지켜주세요.
3. **62차**: 58차가 만드는 `baseNeutral`/`category-theme.ts` 변경과는 무관하지만,
   `backdrop-prompt-templates.ts`를 건드리는 건 57차와 같은 영역이라 57차 변경이
   완전히 반영된 뒤에 시작해주세요.
4. **61차**: 4개 중 가장 범위가 크고(파이프라인 배관 수정) 실제 생성 검증도
   필요해서 마지막에 배치했습니다. 59/60/62차가 끝난 뒤 착수해주세요.

## 비용 원칙

59·61·62차는 실제 생성이 필요한 부분이 있지만, 각각 **카테고리 1개당 1회**로
제한했습니다. 60차는 100% 무료(코드+무료 캡처)입니다. 전체 4개 라운드를 합쳐도
실제 생성 호출은 최대 3회(59차 전자제품 1회, 61차 1회, 62차 화장품 1회) 수준으로
설계했습니다.
