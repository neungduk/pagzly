## 1. 히어로 워드마크 대비 (전 카테고리)

118차 §3-4에서 확인된 원인: 워드마크가 `top≈73px`(히어로 상단)에 있는데, 97차 그라디언트 오버레이는 **하단→상단으로 옅어지는 방향**이라 상단은 오버레이가 거의 0입니다. 108차 카테고리 패턴도 히어로 포토 레이어 위에는 안 올라갑니다. 결과: 밝은 히어로 사진 위에서 흰 워드마크가 `drop-shadow-sm` 하나로만 버팁니다.

### 고칠 것

`lib/hero-brand-mark.ts`(109차) 렌더 지점에서 아래 중 **하나를 택해** 적용하세요 — 이미지 재생성 없이 CSS/구조만으로 되는 방법 우선:

- (a) 워드마크 바로 뒤에 **작은 로컬 그라디언트/블러 패치**(워드마크 영역만 덮는 반투명 검정 pill 또는 짧은 그라디언트)를 추가 — 97차 히어로 전체 그라디언트와는 별개로, 워드마크 주변에만 작용.
- (b) 또는 97차 `getHeroGradient`의 상단 opacity를 워드마크가 있는 카테고리에 한해 아주 살짝(예: 0 → 0.08 정도) 올리기 — 단, 97차가 히어로 상단을 일부러 밝게 둔 이유(사진이 안 가려 보이게)가 있으면 그 이유를 먼저 확인하고, 사진 노출을 해치지 않는 선에서만 하세요.
- 어느 쪽이든 **밝은 히어로 사진 픽스처와 어두운 히어로 사진 픽스처 양쪽에서** 대비가 충분한지 확인하세요(밝은 쪽이 문제였으니 밝은 쪽 우선 확인).

## 2. 식품 크기비교 다이어그램 대비

`118cha-food-diagram.png`를 제가 직접 봤습니다. 골드/올리브 선·라벨이 크림 배경 위에서 읽히긴 하지만 힘이 약합니다. `lib/size-comparison-diagram.ts` 또는 식품 카테고리 테마의 다이어그램 스트로크 색상을 category-theme의 `deepAccent`(더 진한 톤)로 바꾸거나, 라벨 텍스트에 약한 배경 칩을 주세요. **카테고리 테마 색상 범위 안에서**만 조정하세요(110차 원칙 — 새 팔레트 금지).

## 3. 생활용품 카테고리 패턴 누락

118차에서 확인: `CATEGORY_PATTERN_SVG`(108차가 추가한 맵)에 **생활용품 키가 없습니다.** 어떤 파일의 어떤 맵인지 108차 커밋 내역에서 찾아 생활용품 키를 추가하세요 — 다른 카테고리(예: 반려동물의 발자국 패턴처럼 카테고리 무드에 맞는 심플한 SVG 점/선 패턴)와 같은 방식으로, **불투명도 4~6%** 원칙(108차 §2-3)을 지키세요.
