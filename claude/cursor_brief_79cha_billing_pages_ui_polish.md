# 79차 — 결제 페이지(토큰 팩 구매 / 구독) UI 개편

생성: 2026-09-02

## 배경

사용자가 `/billing/packs` 실제 화면 스크린샷을 보여주며: "이거 UI도 보기좋게 개편좀 해줘." 지금 화면은 기능은 다 맞지만(78차에서 상단 요약 바 + 상호 링크까지 추가됨), 디자인이 밋밋합니다 — 흰 배경 카드 2개, 평범한 텍스트, 강조 요소가 전혀 없어서 어떤 팩이 더 나은 선택인지 한눈에 안 들어옵니다.

`app/billing/subscribe/page.tsx`도 `app/billing/packs/page.tsx`와 **완전히 같은 카드 패턴**(`rounded-2xl border border-line bg-white p-6 shadow-sm`, `BillingAccountSummary` 컴포넌트 공유)을 쓰고 있습니다. 팩 페이지만 새 디자인으로 바꾸면, 팩 페이지에서 "구독 보기"를 눌렀을 때 갑자기 예전 디자인이 나와서 부자연스럽습니다. **이번 라운드는 두 페이지 모두에 같은 리디자인을 적용**합니다.

## 지켜야 할 것 — 기존 디자인 토큰만 사용

새 색상을 도입하지 마세요. 지금 코드 전체가 쓰는 토큰만 조합해서 개선합니다:

- `ink` (텍스트/짙은 배경), `registration-red` (강조/CTA), `paper` (배경), `line` (테두리/중립)
- 각각의 투명도 변형(`/5`, `/10`, `/40`, `/60`, `/70` 등)은 자유롭게 사용
- 새 hex 색상, 그라디언트 배경, 아이콘 라이브러리 신규 설치 없음 — 인라인 SVG나 기존 톤 조합으로 해결

## 작업 A — `components/BillingAccountSummary.tsx` 개편

지금은 한 줄짜리 알약(pill) 안에 텍스트만 있습니다 (`현재 보유 토큰: 11,500개 · 현재 요금제: 프로`). 이걸 **두 개의 스탯 블록으로 나눈 카드**로 바꿔주세요:

- 왼쪽: "보유 토큰" 레이블 + 큰 숫자(`11,500` + 작은 "개"), 오른쪽: "현재 요금제" 레이블 + 값(`프로` 또는 활성 구독 없으면 `구독 없음`) — 두 블록 사이에 세로 구분선(`border-line`).
- 카드 자체에 은은한 테두리+그림자(`border border-line shadow-sm`) 정도로, 기존 카드들과 톤이 튀지 않게.
- prop 시그니처(`balance`, `activeTier`)는 그대로 유지 — 두 페이지 다 그대로 재사용 가능해야 합니다.

## 작업 B — 팩/티어 카드에 "추천" 강조

지금은 두 카드(팩 페이지) / 세 카드(구독 페이지)가 시각적으로 동일한 무게라 어떤 걸 고르는 게 이득인지 안 보입니다.

- **팩 페이지**: `1,500토큰 팩`(토큰당 30원, 500토큰 팩은 34원)에 "추천" 배지 — 카드 우측 상단에 작은 pill(`bg-registration-red text-white`), 카드 테두리도 `border-2 border-registration-red`로 다른 카드(`border border-line`)와 구분.
- **구독 페이지**: 중간 티어 `그로스`에 같은 방식으로 "추천" 배지 (SaaS 프라이싱 페이지의 일반적인 패턴 — 중간 티어를 미는 것).
- "토큰당 약 N원" 문구를 지금처럼 평문으로 두지 말고, 작은 태그/배지 형태(`inline-flex rounded-full bg-line/30 px-2 py-0.5`)로 스캔하기 쉽게.
- 카드에 `transition` + `hover:shadow-md hover:-translate-y-0.5` 정도의 미세한 호버 반응 추가 (버튼 하나뿐인 정적 카드보다 인터랙티브하게).
- 카드 내부 정렬/여백을 점검해서 팩 2장이든 티어 3장이든 높이가 맞고 버튼이 카드 하단에 정렬되는 지금 방식(`mt-auto`)은 유지.

## 작업 C — 헤더 영역 정리

- "토큰 팩 구매" / "구독 플랜 선택" 타이틀 위에 작은 eyebrow 라벨(예: "PAGZLY 토큰" 같은 옅은 소문자/트래킹 텍스트, `text-xs uppercase tracking-wide text-ink/40`) 하나 추가해서 위계를 명확히 하는 정도면 충분합니다 — 과한 장식(그라디언트 배경, 큰 일러스트 등) 추가하지 마세요. 지금 헤더(`border-b border-line`, 로고)는 그대로 유지.

## 하지 않는 것

- 결제 로직, 가격, 토큰 수, 티어 구성 등 데이터는 전혀 바꾸지 않습니다 — 순수 시각적 리디자인.
- `BillingAccountSummary`의 prop 시그니처, `/api/billing/purchase-pack`, `/api/billing/subscribe`, 토스페이먼츠 연동 코드는 손대지 않습니다.
- 78차에서 추가한 상호 링크("구독 보기" / "토큰 팩 구매") 텍스트/이동 경로 자체는 유지 — 스타일만 다듬고 싶으면 다듬어도 되지만 없애거나 위치를 크게 옮기지 마세요.
- 새 아이콘 라이브러리·폰트·컬러 시스템 도입 없음.

## 검증 방법

- `/billing/packs`, `/billing/subscribe` 두 화면 모두 개편 전/후 스크린샷 비교.
- 두 페이지의 카드/요약 바 스타일이 서로 일관되게 보이는지 확인 (한쪽만 예쁘고 다른 쪽만 옛날 스타일이면 안 됨).
- 모바일 폭에서 카드가 1열로 쌓일 때도 "추천" 배지·요약 카드가 깨지지 않는지 확인.
- 기존 기능(결제 버튼 클릭, 로딩/에러 상태, 상호 링크 이동) 회귀 없는지 확인.
- `npx tsc --noEmit` 에러 0건.
