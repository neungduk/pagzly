# 216차 실행 검증 (Cursor 완료 보고 → Claude 독립 재검증)

생성: 2026-09-17 · 유료 허가 정확히 1건 소진(`TEST_MODE=false`) · QA 전용 코드 변경 1건 → 되돌림 확인

## 결론

**Cursor의 보고는 정확합니다.** `qaBypassGraspSafeguard: true`로 세이프가드를 우회해
`pasteCutoutOnScene()`이 실제로 실행됐고 `method: "pixel-paste"`로 성공했습니다 —
214/215차 8건 전부가 `nano-banana-fallback`이었던 것과 달리, 이번엔 211차 매칭 경로가
실사에서 처음으로 호출됐습니다. 다만 **육안 확인 결과 품질은 Cursor의 자체 소견대로
자연스럽지 않습니다** — 컷아웃이 원본 위에 떠 보이고, 색온도가 원본과 크게 어긋나며,
접촉 그림자·그레인이 거의 없습니다. 코드 변경은 브리프 범위(새 선택적 파라미터 1개,
분기 추가만)를 정확히 지켰고, **검증 후 완전히 되돌려졌음을 grep으로 직접 확인**했습니다.

## 4. 산출 이미지 육안 확인 (핵심 검증 목표)

`electronics-composite.png`와 `electronics-lifestyle.jpeg`(원본)를 나란히 직접
열어봤습니다:

- **경로 확인**: 214/215차의 "장면 전체가 다시 그려진 고품질 재구성"과 완전히
  다른 결과물 — 원본 사진의 배경·손·기존 이어폰 케이스가 **픽셀 단위로 그대로**
  남아있고, 그 위에 작은 컷아웃(블루/오렌지 조명의 스튜디오 이어버드+케이스)이
  얹혀 있음. 이것이 `pixel-paste`(장면 재생성이 아니라 컷아웃을 원본에 붙이는
  방식)의 특징적 산출물이며, `nano-banana-fallback`과는 육안으로도 명확히 구분됨
  → **method=pixel-paste라는 보고가 이미지 자체로도 뒷받침됨**.
- **품질 문제, 보고서 소견과 일치**:
  - 원본의 검은 오픈 케이스가 지워지지 않고 그대로 비쳐 보임 — 교체가 아니라
    덧붙인 모양새.
  - 컷아웃의 파란색/주황색 스튜디오 조명이 원본의 어둡고 중립적인 실내 조명과
    뚜렷하게 충돌 — 211차 화이트밸런스 매칭이 호출됐다 해도 이 정도의 극단적
    색역 차이를 흡수하지 못한 것으로 보임.
  - 접촉 그림자가 거의 없어 손바닥 위에 붕 뜬 것처럼 보임.
  - 원본 암부의 디지털 그레인이 컷아웃 표면엔 보이지 않아 스튜디오 매끈함이
    그대로 남음.
  - 컷아웃 크기·위치가 원본 케이스와 어긋나 손가락 사이 그립처럼 보이지 않음
    (unreliable placement를 강제로 사용한 결과와 일치).

실제로 무엇인지 구체적으로 보여준 유의미한 결과이기도 합니다 — 세이프가드가
과도하게 보수적인 게 아니라, 오히려 근거가 있었을 가능성을 시사합니다.

## 참고 — 이 라운드가 새로 드러낸 것

세이프가드를 우회했음에도 결과가 부자연스럽다는 것은, 214/215차에서 세운 가설
("세이프가드 임계값이 지나치게 보수적이라 실사용 사진 대부분을 불필요하게
걸러낸다")에 대한 **반대 증거**이기도 합니다. 이 electronics 페어는 애초에
상품컷의 조명·색역이 배경과 근본적으로 다른 "매칭이 어려운 조합"이었을
가능성이 있고, 세이프가드는 그런 조합을 걸러내는 데 어느 정도 제 역할을
하고 있었다고 볼 수도 있습니다. 즉 이번 결과는 "세이프가드를 낮추자"는
결론이 아니라 "매칭 강도 자체를 보강하거나, 상품컷·배경 간 색역 차이가
큰 조합에서는 애초에 픽셀 페이스트보다 nano-banana-fallback이 더 나은
선택일 수 있다"는 방향의 질문을 새로 제기합니다.
