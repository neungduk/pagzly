# 58차 — 페이지 전체 색상 통일감 (baseNeutral 카테고리 분리)

생성: 2026-09-01

## 배경

57차 채점(기준 1~5, `claude/pagzly-quality-baseline-2026.md` 참고) 결과 **기준 1
(페이지 전체 색상 통일감)이 5개 카테고리 전부 불합격**입니다. 51차 QA 스크린샷을
24구간으로 나눠 평균색을 뽑아보니, 히어로 배너 1~2구간만 카테고리 색이고 나머지
60~70% 구간이 카테고리 무관하게 거의 동일한 크림색(`#f8f6f0`~`#eeece7`)으로
수렴합니다.

원인을 코드에서 특정했습니다. `lib/category-theme.ts`의 `CATEGORY_THEMES`를 보면:

```ts
"의류/패션": theme(..., BRAND.paper, ...),      // baseNeutral
"화장품/뷰티": theme(..., BRAND.paper, ...),     // baseNeutral
"식품/건강기능식품": theme(..., BRAND.paper, ...), // baseNeutral
"전자제품": theme(..., "#F5F7F8", ...),         // baseNeutral (사실상 동일)
"생활용품": theme(..., BRAND.paper, ...),        // baseNeutral
"반려동물": theme(..., BRAND.paper, ...),        // baseNeutral
```

6개 카테고리 중 5개가 `baseNeutral`로 완전히 동일한 `BRAND.paper`(`#FAF8F3`)를
쓰고, 전자제품도 `#F5F7F8`로 사실상 무채색이라 육안 차이가 없습니다. 게다가
`lib/design-tokens.ts`의 `getSectionBackground` 함수엔 이렇게 주석이 달려
있습니다:

```ts
/** 섹션 배경 — baseNeutral은 고정, accent 계열만 은은한 그라데이션으로 리듬을 만든다. */
```

즉 지금 구조는 "카테고리색은 accent에만 아주 옅게(패턴별 8~42% 알파) 묻히고,
본문 대부분을 차지하는 바탕색(baseNeutral)은 처음부터 카테고리와 무관하게
고정"하도록 **의도적으로 설계**되어 있습니다. 이게 "결국 다 비슷한 베이지"라는
사용자 체감의 근본 원인입니다 — 53차에서 다양화한 건 accent 색조였지, 페이지
대부분을 차지하는 바탕색 자체는 그때도 지금도 손대지 않았습니다.

## 이번 라운드 목표

**baseNeutral을 카테고리마다 육안으로 구분되게 만드는 것.** 베르가모/LACTO-5X/
이어버드 레퍼런스처럼 "쨍한 색"을 쓰자는 게 아니라, 바탕색 자체가 그 카테고리
색의 아주 옅은 변형이어서 히어로부터 마지막 섹션까지 계속 "이 카테고리구나"가
느껴지게 하는 게 목표입니다.

## 작업 A — `category-theme.ts`의 baseNeutral을 카테고리별로 분리

`lib/design-tokens.ts`에 이미 `BRAND_SOFT`(slate/mustard/red)가 있지만, 이건
배지·필용으로 쓰기엔 적당히 진한 색이라 대면적 바탕색으로 쓰면 너무 쨍해질 수
있습니다. `baseNeutral` 전용으로 그보다 훨씬 옅은 톤(대략 `BRAND.paper`에 각
카테고리 accent를 4~7% 정도만 섞은 수준)을 6개 카테고리 + `DEFAULT_THEME` 각각에
새로 만들어 대입해주세요. `hexToRgba`를 참고해서 두 hex를 알파 비율로 섞는 간단한
mix 헬퍼를 하나 추가해도 되고, 계산해서 리터럴 hex로 박아넣어도 됩니다 — 어느
쪽이든 6개 값이 서로 명확히 다른 색이어야 합니다 (같은 accent를 공유하는
카테고리끼리도 baseNeutral만큼은 구분되게).

- 의류/패션 (accent: ink) → 아주 옅은 그레이지/웜그레이
- 화장품/뷰티 (accent: slateBlue) → 아주 옅은 블루그레이
- 식품/건강기능식품 (accent: mustard) → 아주 옅은 웜크림/골드톤
- 전자제품 (accent: slateBlue, 화장품과 accent 동일) → 화장품과는 다른 방향의
  옅은 쿨톤(예: 더 차갑고 밝은 그레이) — 이번 라운드에서 accent 자체를 바꾸진
  않지만 baseNeutral만으로도 최대한 구분되게
- 생활용품 (accent: slateBlue) → 마찬가지로 화장품·전자제품과 다른 옅은 톤으로
  구분
- 반려동물 (accent: registrationRed) → 아주 옅은 웜핑크/테라코타

## 작업 B — 저알파 패턴 미세 조정 (필요시에만)

`getSectionBackground`의 패턴 A(`accentSoftA`)와 E(`accentE`/`deepAccentE`)는
그라데이션이 baseNeutral에서 시작하거나 baseNeutral로 끝나서, 작업 A를 해도
화면 대부분이 여전히 밋밋해 보일 수 있습니다. 작업 A 적용 후 캡처해서 육안으로
확인했을 때 카테고리 색이 여전히 약하게 느껴지면, E 패턴의 `accentE`
(`0.08`→`0.12` 정도), `deepAccentE`(`0.07`→`0.1` 정도)만 소폭 올려주세요.
**패턴 구조(A/B/C/D/E 순환, 몇 단계 그라데이션인지)는 건드리지 마세요** — 알파
숫자만 미세 조정.
