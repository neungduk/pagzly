# 상세페이지 업그레이드 백로그 (462차 코드 읽기 감사)

**범위와 한계**: 폰 세션이라 코드만 읽었다(캡처·측정 없음). `lib/export-detail-html.ts`(2.5천 줄)와 `components/DetailSectionRenderer.tsx`(6.4천 줄)를 **전수가 아니라 위험 패턴 검색(nowrap·고정 높이·overflow hidden·line-clamp·열 수 고정)으로 표본 점검**했다. 아래 "미감사"는 읽지 못한 영역이다. 심각도·난이도는 읽은 코드 기준 추정이며 눈으로 확인한 것이 아니다.
